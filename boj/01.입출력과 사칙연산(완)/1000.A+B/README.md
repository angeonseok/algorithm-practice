# 1000.A+B

## 문제 설명
두 정수 A와 B를 입력받은 다음, A+B를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 A와 B가 주어진다. (0 < A, B < 10)

## 출력
첫째 줄에 A+B를 출력한다.

## 풀이 정리

### 핵심 아이디어
한 줄에 붙어 오는 두 수를 split으로 갈라서 int 씌우고 더함. 이 입력 한 줄이 뒤 문제들에서 계속 재탕된다.

### 시간복잡도
O(1). 입력 한 줄 읽고 덧셈 하나.

### 구현 포인트
- split 결과는 문자열이라 map(int, ...) 안 씌우면 더하기가 아니라 이어붙이기가 됨
- a, b 한 방에 언패킹으로 받아두면 아래가 깔끔함
