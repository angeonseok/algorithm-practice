# 1008.A나누기B

## 문제 설명
두 정수 A와 B를 입력받은 다음, A/B를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 A와 B가 주어진다. (0 < A, B < 10)

## 출력
첫째 줄에 A/B를 출력한다.
실제 정답과 출력값의 절대오차 또는 상대오차가 10-9 이하이면 정답이다.

## 풀이 정리

### 핵심 아이디어
정수 몫이 아니라 실수 나눗셈이다. 슬래시 하나만 쓰면 파이썬이 알아서 float로 뱉는다.

### 시간복잡도
O(1). 한 줄 받아서 나누면 끝.

### 구현 포인트
- // 쓰면 몫만 나와서 바로 틀림. 여기선 / 하나짜리로 가야지
- 오차 1e-9까지 봐주는데 파이썬 float 기본 출력이 자릿수를 넉넉히 찍어줘서 그냥 print해도 통과
- 출력 자리수 맞춘다고 round 같은 거 손대면 오히려 손해
