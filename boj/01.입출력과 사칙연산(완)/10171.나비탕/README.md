# 10171.나비탕

## 문제 설명
아래 예제와 같이 고양이를 출력하시오.

## 입력
없음

## 출력
고양이를 출력한다.

## 풀이 정리

### 핵심 아이디어
고양이 아스키아트를 네 줄 그대로 찍는다. 알고리즘은 없고 이스케이프 싸움.

### 시간복잡도
O(1). 네 줄 출력하고 끝.

### 구현 포인트
- 마지막 줄 `\\(__)|` 는 백슬래시 두 개 박아야 화면에 하나 나옴
- 첫 줄은 `\` 하나로 뒀는데 뒤가 공백이라 이스케이프로 안 잡히고 그냥 통과함. 원래는 두 개가 안전
- 따옴표 들어가는 줄은 `\'` 로 막아뒀다. 문자열을 작은따옴표로 감쌌으니까
- 공백 한 칸 어긋나도 틀림. 예제 옆에 놓고 눈으로 대조하자
