# 10172.보신탕

## 문제 설명
아래 예제와 같이 개를 출력하시오.

## 입력
없음

## 출력
개를 출력한다

## 풀이 정리

### 핵심 아이디어
나비탕이랑 같은 결. 개 그림 다섯 줄을 print로 때려박음.

### 시간복잡도
O(1). 그림 다섯 줄이 전부라 복잡도 따질 게 없다.

### 구현 포인트
- 백슬래시 개수 세는 게 이 문제의 전부. 마지막 줄은 네 개 써야 두 개가 나온다
- 그림에 큰따옴표가 섞여 있어서 문자열은 작은따옴표로 감싸는 게 편함
- 눈으로 세다 보면 헷갈리니 예제 출력 옆에 놓고 한 줄씩 대조하자
