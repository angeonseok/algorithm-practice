# 10430.나머지

## 문제 설명
(A+B)%C는 ((A%C) + (B%C))%C 와 같을까? (A×B)%C는 ((A%C) × (B%C))%C 와 같을까? 세 수 A, B, C가 주어졌을 때, 위의 네 가지 값을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 A, B, C가 순서대로 주어진다. (2 ≤ A, B, C ≤ 10000)

## 출력
첫째 줄에 (A+B)%C, 둘째 줄에 ((A%C) + (B%C))%C, 셋째 줄에 (A×B)%C, 넷째 줄에 ((A%C) × (B%C))%C를 출력한다.

## 풀이 정리

### 핵심 아이디어
모듈러가 덧셈 곱셈에 분배되는지 직접 찍어보라는 문제. 네 식을 그대로 옮겨 적으면 값이 두 쌍으로 같게 나온다.

### 시간복잡도
O(1). 식 네 개 찍고 종료.

### 구현 포인트
- 괄호를 문제에 나온 그대로 옮기는 게 안전함. 연산자 우선순위 믿고 괄호 빼면 꼬인다
- 나중에 숫자 크게 곱할 때 매 계산마다 나누는 습관, 그 근거가 여기 있음
- 출력 네 줄 순서 문제에서 시킨 대로
