# 2588.곱셈

## 문제 설명
(세 자리 수) × (세 자리 수)는 다음과 같은 과정을 통하여 이루어진다.(1)과 (2)위치에 들어갈 세 자리 자연수가 주어질 때 (3), (4), (5), (6)위치에 들어갈 값을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 (1)의 위치에 들어갈 세 자리 자연수가, 둘째 줄에 (2)의 위치에 들어갈 세자리 자연수가 주어진다.

## 출력
첫째 줄부터 넷째 줄까지 차례대로 (3), (4), (5), (6)에 들어갈 값을 출력한다.

## 풀이 정리

### 핵심 아이디어
손으로 하는 세로셈을 그대로 옮겼다. 둘째 수를 list(input())으로 문자 단위로 쪼개서 자릿수 하나씩 꺼내 곱하는 방식.

### 시간복잡도
O(1). 자릿수가 세 개로 고정이라 곱셈 네 번이면 끝.

### 구현 포인트
- b[0]이 백의 자리, b[2]가 일의 자리. 출력은 일의 자리부터 시작이라 인덱스가 거꾸로 간다. 인덱스 조심
- list(input())으로 받으면 원소가 전부 문자라 곱하기 전에 int() 다시 씌워야 함
- 마지막 줄은 자릿수를 100, 10, 1로 다시 조립해서 곱함. int(b)로 한 방에 해도 되는데 세로셈 흐름 그대로 두는 쪽을 골랐다
