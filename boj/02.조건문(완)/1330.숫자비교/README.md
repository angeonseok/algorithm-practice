# 1330.숫자비교

## 문제 설명
두 정수 A와 B가 주어졌을 때, A와 B를 비교하는 프로그램을 작성하시오.

## 입력
첫째 줄에 A와 B가 주어진다. A와 B는 공백 한 칸으로 구분되어져 있다.

## 출력
첫째 줄에 다음 세 가지 중 하나를 출력한다.
A가 B보다 큰 경우에는 '>'를 출력한다.
A가 B보다 작은 경우에는 '<'를 출력한다.
A와 B가 같은 경우에는 '=='를 출력한다.

## 풀이 정리

### 핵심 아이디어
두 수 크기만 재서 부호 찍으면 끝. if-elif로 세 갈래 나눠놨다.

### 시간복잡도
O(1). 입력 두 개 받고 비교 한 번이 전부.

### 구현 포인트
- 같을 때 출력이 '='이 아니라 '=='다. 출력 양식 조심
- 한 줄에 두 개 들어오니까 map(int, input().split())로 받음
- elif로 묶어서 한 갈래만 타게 함
