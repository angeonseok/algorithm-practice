# 10951.A+B-4

## 문제 설명
각 테스트 케이스마다 A+B를 출력한다.

## 입력
입력은 여러 개의 테스트 케이스로 이루어져 있다.
각 테스트 케이스는 한 줄로 이루어져 있으며, 각 줄에 A와 B가 주어진다. (0 < A, B < 10)

## 출력
각 테스트 케이스마다 A+B를 출력한다.

## 풀이 정리

### 핵심 아이디어
케이스 개수를 안 알려주니까 입력 끊길 때까지 돌린다. try~except로 EOFError 잡아서 탈출.

### 시간복잡도
O(T). 들어온 입력 줄 수만큼.

### 구현 포인트
- input()은 입력 다 떨어지면 EOFError를 던진다. 안 잡으면 런타임 에러 뜸
- while 1로 무한루프 걸고 예외에서만 break
- 0 0 종료 조건도 같이 껴놨는데 이 문제는 EOF만으로 충분함
