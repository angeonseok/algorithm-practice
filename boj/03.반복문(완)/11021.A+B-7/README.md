# 11021.A+B-7

## 문제 설명
두 정수 A와 B를 입력받은 다음, A+B를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 테스트 케이스의 개수 T가 주어진다.
각 테스트 케이스는 한 줄로 이루어져 있으며, 각 줄에 A와 B가 주어진다. (0 < A, B < 10)

## 출력
각 테스트 케이스마다 "Case #x: "를 출력한 다음, A+B를 출력한다. 테스트 케이스 번호는 1부터 시작한다.

## 풀이 정리

### 핵심 아이디어
계산은 그냥 A+B고 출력 양식만 붙었다. f-string으로 Case 번호 찍음.

### 시간복잡도
O(T). 케이스 수만큼만 돌면 됨.

### 구현 포인트
- 케이스 번호가 1부터라 range(1, t+1)로 돌림
- 'Case #i: ' 콜론 뒤 공백 하나까지 그대로. 양식 어긋나면 답 맞아도 틀림
