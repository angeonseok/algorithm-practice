# 2438.별찍기-1

## 문제 설명
첫째 줄에는 별 1개, 둘째 줄에는 별 2개, N번째 줄에는 별 N개를 찍는 문제

## 입력
첫째 줄에 N(1 ≤ N ≤ 100)이 주어진다.

## 출력
첫째 줄부터 N번째 줄까지 차례대로 별을 출력한다.

## 풀이 정리

### 핵심 아이디어
i번째 줄에 별 i개. 문자열 곱셈으로 한 줄씩 만들어서 바로 출력했다.

### 시간복잡도
O(N^2). 줄 수는 N이지만 찍는 별 총합이 N(N+1)/2라 제곱 취급.

### 구현 포인트
- range(1, t+1)로 돌려야 별 1개부터 시작함. range 범위 조심
- 루프 안에서 '*' * i 로 만들고 print 한 방. 굳이 안쪽 for 돌 필요 없다
