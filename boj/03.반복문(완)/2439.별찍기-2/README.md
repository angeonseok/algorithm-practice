# 2439.별찍기-2

## 문제 설명
첫째 줄에는 별 1개, 둘째 줄에는 별 2개, N번째 줄에는 별 N개를 찍는 문제
하지만, 오른쪽을 기준으로 정렬한 별(예제 참고)을 출력하시오.

## 입력
첫째 줄에 N(1 ≤ N ≤ 100)이 주어진다.

## 출력
첫째 줄부터 N번째 줄까지 차례대로 별을 출력한다.

## 풀이 정리

### 핵심 아이디어
2438에서 오른쪽 정렬만 붙은 버전. 앞에 공백 (N-i)개 깔고 뒤에 별 i개 붙이면 끝.

### 시간복잡도
O(N^2). 공백 + 별 합쳐서 매 줄 N칸씩 찍으니까.

### 구현 포인트
- 공백 개수는 t - i. 여기서 i를 잘못 잡으면 삼각형이 반대로 돈다
- 여기도 range(1, t+1). range 범위 조심
- 공백이랑 별을 문자열로 이어붙여서 print 하나로 처리
