# 2739.구구단

## 문제 설명
N을 입력받은 뒤, 구구단 N단을 출력하는 프로그램을 작성하시오.
출력 형식에 맞춰서 출력하면 된다.

## 입력
첫째 줄에 N이 주어진다. N은 1보다 크거나 같고, 9보다 작거나 같다.

## 출력
출력형식과 같게 N*1부터 N*9까지 출력한다.

## 풀이 정리

### 핵심 아이디어
1부터 9까지 곱해서 f-string으로 양식 맞춰 출력. 그 이상 없다.

### 시간복잡도
O(1). 무조건 9줄.

### 구현 포인트
- 'a * i = b' 양식 그대로 찍기. 곱셈 기호 앞뒤 공백 하나씩 놓치면 바로 틀림
- range(1, 10)이라 10은 안 들어감
