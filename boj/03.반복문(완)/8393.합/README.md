# 8393.합

## 문제 설명
n이 주어졌을 때, 1부터 n까지 합을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 n (1 ≤ n ≤ 10,000)이 주어진다.

## 출력
1부터 n까지 합을 출력한다.

## 풀이 정리

### 핵심 아이디어
1부터 n까지 누적. 공식으로 때려도 되는데 걍 for 돌렸다.

### 시간복잡도
O(N). n까지 세면서 더하는 게 전부. 공식 쓰면 O(1)인데 굳이 안 씀.

### 구현 포인트
- range(1, a+1) 이어야 n까지 들어감. a+1 안 하면 하나 모자람
- sum_a = 0 초기화 먼저
