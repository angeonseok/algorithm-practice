# 10818.최소최대

## 문제 설명
N개의 정수가 주어진다. 이때, 최솟값과 최댓값을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 정수의 개수 N (1 ≤ N ≤ 1,000,000)이 주어진다. 둘째 줄에는 N개의 정수를 공백으로 구분해서 주어진다.  모든 정수는 -1,000,000보다 크거나 같고, 1,000,000보다 작거나 같은 정수이다.

## 출력
첫째 줄에 주어진 정수 N개의 최솟값과 최댓값을 공백으로 구분해 출력한다.

## 풀이 정리

### 핵심 아이디어
min/max 함수 안 쓰고 한 번 훑으면서 직접 갱신. 첫 원소로 둘 다 초기화해두고 시작한다.

### 시간복잡도
O(N). 한 바퀴에 최소 최대 둘 다 잡음.

### 구현 포인트
- 0이나 큰 수로 초기화하면 안 되고 n[0]으로 잡아야 안전함. 음수도 들어오니까
- if / elif 로 묶여있는데, 최댓값보다 큰 놈이 동시에 최솟값보다 작을 수는 없어서 문제없음
- 출력은 최소 먼저 최대 나중. 출력 양식 맞추기
