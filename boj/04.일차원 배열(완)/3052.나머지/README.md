# 3052.나머지

## 문제 설명
두 자연수 A와 B가 있을 때, A%B는 A를 B로 나눈 나머지 이다.  예를 들어, 7, 14, 27, 38을 3으로 나눈 나머지는 1, 2, 0, 2이다.  수 10개를 입력받은 뒤, 이를 42로 나눈 나머지를 구한다. 그 다음 서로 다른 값이 몇 개 있는지 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄부터 열번째 줄 까지 숫자가 한 줄에 하나씩 주어진다. 이 숫자는 1,000보다 작거나 같고, 음이 아닌 정수이다.

## 출력
첫째 줄에, 42로 나누었을 때, 서로 다른 나머지가 몇 개 있는지 출력한다.

## 풀이 정리

### 핵심 아이디어
서로 다른 나머지 개수만 물어보니까 set에 던져놓고 크기만 재면 끝. 중복 제거를 자료구조가 알아서 해준다.

### 시간복잡도
O(N). N=10 고정, add가 상수라 사실상 볼 것도 없음.

### 구현 포인트
- 리스트로 하면 중복 체크를 직접 해야 되는데 set이면 그냥 add
- 넣는 값은 원본이 아니라 42로 나눈 나머지. 여기 헷갈리지 말자
- 입력 10번 고정이라 range(10)
