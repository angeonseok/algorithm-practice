# 5597.과제안내신분

## 문제 설명
X대학 M교수님은 프로그래밍 수업을 맡고 있다.  교실엔 학생이 30명이 있는데, 학생 명부엔 각 학생별로 1번부터 30번까지 출석번호가 붙어 있다. 교수님이 내준 특별과제를 28명이 제출했는데, 그 중에서 제출 안 한 학생 2명의 출석번호를 구하는 프로그램을 작성하시오.

## 입력
입력은 총 28줄로 각 제출자(학생)의 출석번호 n(1 ≤ n ≤ 30)가 한 줄에 하나씩 주어진다. 출석번호에 중복은 없다.

## 출력
출력은 2줄이다. 1번째 줄엔 제출하지 않은 학생의 출석번호 중 가장 작은 것을 출력하고, 2번째 줄에선 그 다음 출석번호를 출력한다.

## 풀이 정리

### 핵심 아이디어
1~30 체크용 배열 깔아놓고 낸 놈만 1 박는다. 끝나고 0으로 남은 자리가 답. 번호 범위가 30밖에 안 되니 배열이 제일 편함.

### 시간복잡도
O(30). 입력 28번 받고 30칸 한 번 훑는 게 다라 그냥 상수.

### 구현 포인트
- 0번 인덱스 버리고 쓸 거라 31칸 잡음. 출석번호랑 인덱스를 맞춰놔야 편하다
- 출력 루프는 range(1, 31). 작은 번호부터 도니까 출력 순서가 자동으로 맞음
- 안 낸 놈이 2명인 건 알지만 따로 세지 않고 0인 거 전부 뱉으면 그만
