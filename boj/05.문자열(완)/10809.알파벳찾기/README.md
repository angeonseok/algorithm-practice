# 10809.알파벳찾기

## 문제 설명
알파벳 소문자로만 이루어진 단어 S가 주어진다. 각각의 알파벳에 대해서, 단어에 포함되어 있는 경우에는 처음 등장하는 위치를, 포함되어 있지 않은 경우에는 -1을 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 단어 S가 주어진다. 단어의 길이는 100을 넘지 않으며, 알파벳 소문자로만 이루어져 있다.

## 출력
첫째 줄에 단어 S가 주어진다. 단어의 길이는 100을 넘지 않으며, 알파벳 소문자로만 이루어져 있다.

## 풀이 정리

### 핵심 아이디어
a부터 z까지 문자열 하나 박아두고 그 순서대로 돌면서, 입력에 있으면 index 없으면 -1. 첫 등장 위치만 필요해서 index로 충분하다.

### 시간복잡도
O(26 * N). 알파벳마다 in 검사 한 번 index 한 번씩 문자열을 훑는데 N이 100 이하라 터질 일 없음.

### 구현 포인트
- in으로 있나 보고 index로 또 훑으니까 결국 두 번 도는 셈. 길이가 짧아서 감
- index는 처음 나오는 위치를 주니까 문제가 원하는 조건이랑 딱 맞아떨어짐
- end=" " 붙여서 한 줄에 쭉 이어 찍기
