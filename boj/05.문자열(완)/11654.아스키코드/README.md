# 11654.아스키코드

## 문제 설명
알파벳 소문자, 대문자, 숫자 0-9중 하나가 주어졌을 때, 주어진 글자의 아스키 코드값을 출력하는 프로그램을 작성하시오.

## 입력
알파벳 소문자, 대문자, 숫자 0-9 중 하나가 첫째 줄에 주어진다.

## 출력
입력으로 주어진 글자의 아스키 코드 값을 출력한다.

## 풀이 정리

### 핵심 아이디어
ord() 한 줄. 문자를 아스키 값으로 바꿔주는 내장 함수 그대로 씀.

### 시간복잡도
O(1). ord 한 번 부르고 바로 출력.

### 구현 포인트
- ord()가 문자 > 숫자, chr()이 숫자 > 문자. 방향 헷갈리지 말자
- input()은 어차피 문자열로 들어오니까 int 변환 같은 거 끼우면 안 됨
