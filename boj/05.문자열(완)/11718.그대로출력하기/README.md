# 11718.그대로출력하기

## 문제 설명
입력 받은 대로 출력하는 프로그램을 작성하시오.

## 입력
입력이 주어진다. 입력은 최대 100줄로 이루어져 있고, 알파벳 소문자, 대문자, 공백, 숫자로만 이루어져 있다. 각 줄은 100글자를 넘지 않으며, 빈 줄은 주어지지 않는다. 또, 각 줄은 공백으로 시작하지 않고, 공백으로 끝나지 않는다.

## 출력
입력받은 그대로 출력한다.

## 풀이 정리

### 핵심 아이디어
몇 줄 들어올지 안 알려주니까 무한루프 돌리다가 input()이 터지면 break. 입력 끝나는 걸 예외로 잡는 방식이다.

### 시간복잡도
O(N). 줄 수 N만큼 읽고 바로 뱉는다. 모아두는 게 없어서 메모리도 안 먹음.

### 구현 포인트
- 입력 다 떨어지면 input()이 EOFError 던짐. try/except로 받아서 빠져나오는 게 이 문제 전부다
- while 1로 돌리고 탈출 조건은 오직 예외뿐
- 읽은 줄 손대지 말고 그대로 print
