# 11720.숫자합

## 문제 설명
N개의 숫자가 공백 없이 쓰여있다. 이 숫자를 모두 합해서 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 숫자의 개수 N (1 ≤ N ≤ 100)이 주어진다. 둘째 줄에 숫자 N개가 공백없이 주어진다.

## 출력
입력으로 주어진 숫자 N개의 합을 출력한다.

## 풀이 정리

### 핵심 아이디어
숫자가 공백 없이 붙어 있으니 문자열 상태 그대로 두고 한 글자씩 int 떠서 누적.

### 시간복잡도
O(N). 자릿수만큼 한 번 도는 게 다.

### 구현 포인트
- 첫 줄 N은 받아만 놓고 안 씀. 어차피 문자열 돌면 길이만큼 알아서 돌아감
- 둘째 줄을 int로 통째로 받으면 자릿수를 못 쪼갠다. 문자열로 받아야지
- int(i)로 한 글자씩 바꿔서 t에 더하기
