# 2675.문자열반복

## 문제 설명
문자열 S를 입력받은 후에, 각 문자를 R번 반복해 새 문자열 P를 만든 후 출력하는 프로그램을 작성하시오. 즉, 첫 번째 문자를 R번 반복하고, 두 번째 문자를 R번 반복하는 식으로 P를 만들면 된다.  S에는 QR Code "alphanumeric" 문자만 들어있다. QR Code "alphanumeric" 문자는 0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ\$%*+-./: 이다.

## 풀이 정리

### 핵심 아이디어
테케마다 R이랑 S 받고, S를 글자 단위로 쪼개서 x * R로 늘려 찍는다. 반복 찍는 걸 for로 또 돌릴 게 아니라 문자열 곱셈한테 떠넘기는 거임.

### 시간복잡도
O(T * R * |S|). 테케마다 문자열 길이 곱하기 반복 횟수만큼 찍어내는 양이다.

### 구현 포인트
- split으로 받은 r은 문자열이라 int(r) 안 씌우면 문자열 * 문자열이 돼서 바로 터짐
- end=""로 따닥따닥 붙여 찍고 한 테케 끝나면 print()로 줄넘김
- 입력이 'R S' 순서다. r이 횟수, s가 문자열인데 이거 뒤집어 받으면 다 꼬임
