# 27866.문자와문자열

## 문제 설명
단어 S와 정수 i가 주어졌을 때, S의 i번째 글자를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 영어 소문자와 대문자로만 이루어진 단어 S가 주어진다. 단어의 길이는 최대 1000이다. 둘째 줄에 정수 i가 주어진다.

## 출력
S의 i번째 글자를 출력한다.

## 풀이 정리

### 핵심 아이디어
i번째 글자 내놓으라는 거니까 인덱싱 한 방으로 끝. 1부터 세는 걸 0부터로 내려주기만 하면 됨.

### 시간복잡도
O(N). 꺼내는 건 인덱스 접근이라 상수인데, list(input())가 길이만큼 훑고 지나가서 결국 N에 걸린다.

### 구현 포인트
- 문제는 1번째부터 세는데 파이썬은 0부터. a-1 빼먹으면 한 칸씩 밀림
- 입력이 두 줄이라 input()을 두 번 받는다. 순서 바뀌지 않게 조심
- list로 감싸긴 했는데 문자열 그대로 인덱싱해도 결과 같음
