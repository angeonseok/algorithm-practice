# 9086.문자열

## 문제 설명
문자열을 입력으로 주면 문자열의 첫 글자와 마지막 글자를 출력하는 프로그램을 작성하시오.

## 입력
입력의 첫 줄에는 테스트 케이스의 개수 T(1 ≤ T ≤ 10)가 주어진다. 각 테스트 케이스는 한 줄에 하나의 문자열이 주어진다. 문자열은 알파벳 A~Z 대문자로 이루어지며 알파벳 사이에 공백은 없으며 문자열의 길이는 1000보다 작다.

## 출력
각 테스트 케이스에 대해서 주어진 문자열의 첫 글자와 마지막 글자를 연속하여 출력한다.

## 풀이 정리

### 핵심 아이디어
b[0] + b[-1] 붙여서 리스트에 모아뒀다가 마지막에 한 번에 출력. 문자열 길이는 볼 필요도 없고 양 끝만 집으면 끝.

### 시간복잡도
O(T). T는 테스트케이스 수. 문자열이 아무리 길어도 인덱싱 두 번이라 케이스당 상수.

### 구현 포인트
- 마지막 글자는 b[-1]이 제일 짧다. len(b)-1 안 써도 됨
- 바로 출력 안 하고 o에 모았다가 따로 도는 구조
- 첫 줄 T 받고 그 수만큼 입력받는 거 잊지 말자
