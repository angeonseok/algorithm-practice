# 10988.펠린드롬 확인

## 문제 설명
알파벳 소문자로만 이루어진 단어가 주어진다.  이때, 이 단어가 팰린드롬인지 아닌지 확인하는 프로그램을 작성하시오. 팰린드롬이란 앞으로 읽을 때와 거꾸로 읽을 때 똑같은 단어를 말한다.  level, noon은 팰린드롬이고, baekjoon, online, judge는 팰린드롬이 아니다.

## 입력
첫째 줄에 단어가 주어진다. 단어의 길이는 1보다 크거나 같고, 100보다 작거나 같으며, 알파벳 소문자로만 이루어져 있다.

## 출력
첫째 줄에 팰린드롬이면 1, 아니면 0을 출력한다.

## 풀이 정리

### 핵심 아이디어
슬라이싱으로 뒤집어서 원본이랑 같은지만 비교. 투 포인터까지 갈 것도 없이 a[::-1] 한 줄로 견적 나옴.

### 시간복잡도
O(N). N은 문자열 길이. 뒤집는 것도 비교도 한 번씩 훑는 정도.

### 구현 포인트
- a[::-1]이 뒤집기. step -1인 거 헷갈리지 말자
- 출력이 True/False가 아니라 1/0이다. 출력 양식 맞추기
