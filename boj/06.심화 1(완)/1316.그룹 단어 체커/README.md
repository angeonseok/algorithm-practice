# 1316.그룹 단어 체커

## 문제 설명
그룹 단어란 단어에 존재하는 모든 문자에 대해서, 각 문자가 연속해서 나타나는 경우만을 말한다. 예를 들면, ccazzzzbb는 c, a, z, b가 모두 연속해서 나타나고, kin도 k, i, n이 연속해서 나타나기 때문에 그룹 단어이지만, aabbbccb는 b가 떨어져서 나타나기 때문에 그룹 단어가 아니다. 단어 N개를 입력으로 받아 그룹 단어의 개수를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 단어의 개수 N이 들어온다. N은 100보다 작거나 같은 자연수이다. 둘째 줄부터 N개의 줄에 단어가 들어온다. 단어는 알파벳 소문자로만 되어있고 중복되지 않으며, 길이는 최대 100이다.

## 출력
첫째 줄에 그룹 단어의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
일단 전부 그룹 단어라고 치고 cnt = n에서 시작, 아닌 놈 걸릴 때마다 하나씩 깎는다. 연속이 끝난 글자를 seen에 기록해두고 걔가 또 튀어나오면 탈락.

### 시간복잡도
O(N * L). N은 단어 수(최대 100), L은 단어 길이(최대 100). 단어마다 한 번씩만 훑음.

### 구현 포인트
- 앞 글자랑 다를 때만 seen 체크. 연속으로 붙어 있는 건 그냥 통과
- seen에 넣는 건 word[i][j-1]. 지금 글자가 아니라 방금 연속이 끝난 놈이다
- 탈락시켰으면 break. 안 걸면 한 단어에서 여러 번 깎여서 넌 나가라가 두 번 됨
- 길이 1짜리 단어는 안쪽 루프가 안 돌아서 자동으로 살아남는다
