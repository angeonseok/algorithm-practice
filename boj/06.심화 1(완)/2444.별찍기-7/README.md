# 2444.별찍기-7

## 문제 설명
예제를 보고 규칙을 유추한 뒤에 별을 찍어 보세요.

## 입력
첫째 줄에 N(1 ≤ N ≤ 100)이 주어진다.

## 출력
첫째 줄부터 2×N-1번째 줄까지 차례대로 별을 출력한다.

## 풀이 정리

### 핵심 아이디어
위쪽은 1~n, 아래쪽은 n-1~1 역순으로 두 번 돌린다. 공백 n-i개 + 별 2i-1개 식만 세우면 그 뒤론 손댈 게 없음.

### 시간복잡도
O(N^2). 찍는 문자 수가 결국 별이랑 공백 다 합친 넓이라.

### 구현 포인트
- 별 2*i-1, 공백 n-i. 이 식 하나가 전부다
- 아래쪽 range(n-1, 0, -1). n부터 시작하면 가운데 줄이 두 번 찍힌다
- 공백이랑 별을 한 print에서 이어붙여 찍는다. 나눠 찍으면 줄바꿈 껴서 모양 망함
