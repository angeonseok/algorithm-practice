# 1193.분수 찾기

## 문제 설명
무한히 큰 배열에 다음과 같이 분수들이 적혀있다.
이와 같이 나열된 분수들을 1/1 → 1/2 → 2/1 → 3/1 → 2/2 → … 과 같은 지그재그 순서로 차례대로 1번, 2번, 3번, 4번, 5번, … 분수라고 하자.
X가 주어졌을 때, X번째 분수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 X(1 ≤ X ≤ 10,000,000)가 주어진다.

## 출력
첫째 줄에 분수를 출력한다.

## 풀이 정리

### 핵심 아이디어
대각선 라인 단위로 끊어서 본다. line번째 라인의 끝 번호가 1+2+...+line이라 그게 x를 넘을 때까지만 더하면 x가 어느 라인인지 나오고, 그 안에서 위치는 라인 홀짝으로 방향만 갈림.

### 시간복잡도
O(√X). 라인 끝값이 삼각수라 대략 root(2X)번쯤 돌면 넘어감. X가 천만이어도 4500번 정도.

### 구현 포인트
- k = line_end - x 로 라인 끝에서 몇 칸 떨어졌는지부터 잡고 시작
- 짝수 라인은 a = line - k, b = 1 + k. 홀수 라인은 반대로. 노트에 써보면 바로 견적 나옴
- while 안에서 a, b를 매번 갱신해서 루프 빠져나온 순간 값이 그대로 답이 되는 구조
