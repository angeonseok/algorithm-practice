# 2869.달팽이는 올라가고 싶다

## 문제 설명
땅 위에 달팽이가 있다.
이 달팽이는 높이가 V미터인 나무 막대를 올라갈 것이다.
달팽이는 낮에 A미터 올라갈 수 있다.
하지만, 밤에 잠을 자는 동안 B미터 미끄러진다.
또, 정상에 올라간 후에는 미끄러지지 않는다.
달팽이가 나무 막대를 모두 올라가려면, 며칠이 걸리는지 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 세 정수 A, B, V가 공백으로 구분되어서 주어진다. (1 ≤ B < A ≤ V ≤ 1,000,000,000)

## 출력
첫째 줄에 달팽이가 나무 막대를 모두 올라가는데 며칠이 걸리는지 출력한다.

## 풀이 정리

### 핵심 아이디어
하루씩 시뮬 돌리면 V가 10억이라 터짐. 정상 찍으면 안 미끄러지니까 마지막 날 A만큼 미리 떼놓고, 남은 V-A를 하루 순수 상승분 A-B로 나눈 뒤 1 더하는 식으로 계산.

### 시간복잡도
O(1). 나눗셈 한 번이 전부.

### 구현 포인트
- (v - a) // (a - b) + 1 이 기본. 나머지가 남으면 하루 더 붙여야 한다
- 올림은 ceil 안 쓰고 (v - a) % (a - b) != 0 인지 직접 보고 i += 1. 파이썬 올림을 믿지말자
- 나눗셈이 문제다 항상. B < A 조건이 있어서 a-b가 0 되는 경우는 막혀있음
