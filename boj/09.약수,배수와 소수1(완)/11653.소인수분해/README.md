# 11653.소인수분해

## 문제 설명
정수 N이 주어졌을 때, 소인수분해하는 프로그램을 작성하시오.

## 입력
첫째 줄에 정수 N (1 ≤ N ≤ 10,000,000)이 주어진다.

## 출력
N의 소인수분해 결과를 한 줄에 하나씩 오름차순으로 출력한다. N이 1인 경우 아무것도 출력하지 않는다.

## 풀이 정리

### 핵심 아이디어
root n까지 에라토스테네스로 소수를 먼저 뽑아두고, 그 소수들로 안 나눠질 때까지 계속 나눠가며 출력. 다 나누고 남은 값이 1보다 크면 걔가 마지막 큰 소인수.

### 시간복잡도
O(√N log log √N). 체가 root N(≈3163)까지만 돌고, 나누는 것도 그 안의 소수 개수만큼이라 널널.

### 구현 포인트
- 상한을 root n으로 잡는 근거 : x = a * b 면 a, b 중 하나는 root x보다 클 수 없다. 소인수 분해 목적이면 여기까지만 해도 ㄱㅊ
- 체 안쪽 루프는 i*i부터 시작. 그 아래는 이미 다 죽어있음
- prime * prime > n_p 면 break하고, 남은 n_p를 마지막에 따로 출력해야 큰 소수를 안 놓침
- N이 1이면 루프를 안 타고 n_p도 1이라 자연스럽게 아무것도 안 찍힘
