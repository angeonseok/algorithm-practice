# 1978.소수 찾기

## 문제 설명
주어진 수 N개 중에서 소수가 몇 개인지 찾아서 출력하는 프로그램을 작성하시오.

## 입력
첫 줄에 수의 개수 N이 주어진다. N은 100이하이다.
다음으로 N개의 수가 주어지는데 수는 1,000 이하의 자연수이다.

## 출력
주어진 수들 중 소수의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
수 하나마다 1부터 자기 자신까지 다 훑어서 약수를 모으고, 개수가 딱 2개면 소수로 센다. 입력 크기가 작아서 체까지 갈 것도 없음.

### 시간복잡도
O(N * M). N은 수 개수 100, M은 값 1000. 10만 번이라 그냥 통과.

### 구현 포인트
- 1은 나가라. i < 2면 continue로 컷 안 하면 약수 개수가 1개라 어차피 안 세지지만 명시해두는 게 낫다
- b.clear()로 매번 초기화해야지. 안 하면 앞 수 약수가 그대로 남아있음
- 파일 아래에 에라토스테네스 버전을 주석으로 남겨둠. 이 크기에선 굳이 안 꺼내도 됨
