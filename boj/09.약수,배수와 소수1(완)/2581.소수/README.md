# 2581.소수

## 문제 설명
자연수 M과 N이 주어질 때 M이상 N이하의 자연수 중 소수인 것을 모두 골라 이들 소수의 합과 최솟값을 찾는 프로그램을 작성하시오.
예를 들어 M=60, N=100인 경우 60이상 100이하의 자연수 중 소수는 61, 67, 71, 73, 79, 83, 89, 97 총 8개가 있으므로, 이들 소수의 합은 620이고, 최솟값은 61이 된다.

## 입력
입력의 첫째 줄에 M이, 둘째 줄에 N이 주어진다.
M과 N은 10,000이하의 자연수이며, M은 N보다 작거나 같다.

## 출력

## 풀이 정리

### 핵심 아이디어
M~N 구간을 하나씩 보면서 약수를 root i까지만 찾되 i//j 짝도 같이 담는다. 개수가 2개면 소수라 따로 모아뒀다가 합이랑 맨 앞놈 출력.

### 시간복잡도
O((N-M) * √N). N이 10000이라 구간 전체를 돌아도 100만 안쪽.

### 구현 포인트
- 약수 j 담을 때 짝인 i//j도 같이 담되 other != j 일 때만. 제곱수에서 같은 놈이 두 번 들어간다
- 1부터 i까지 다 돌면 너무 걸려서 범위를 root i 로 줄임
- 소수가 하나도 없으면 -1 한 줄만 출력. 합이랑 최솟값까지 뱉으면 틀림
- p에 오름차순으로 쌓이니까 최솟값은 그냥 p[0]
