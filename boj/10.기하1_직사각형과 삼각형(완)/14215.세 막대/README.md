# 14215.세 막대

## 문제 설명
영선이는 길이가 a, b, c인 세 막대를 가지고 있고, 각 막대의 길이를 마음대로 줄일 수 있다.
영선이는 세 막대를 이용해서 아래 조건을 만족하는 삼각형을 만들려고 한다.
각 막대의 길이는 양의 정수이다
세 막대를 이용해서 넓이가 양수인 삼각형을 만들 수 있어야 한다.
삼각형의 둘레를 최대로 해야 한다.
a, b, c가 주어졌을 때, 만들 수 있는 가장 큰 둘레를 구하는 프로그램을 작성하시오.

## 풀이 정리

### 핵심 아이디어
그리디. 정렬해두면 어느 놈이 최장인지 고민 안 해도 되고, 삼각부등식 깨졌을 때 젤 긴 놈 하나만 손봐주면 둘레가 최대가 됨.

### 시간복잡도
O(1). 원소 3개짜리 정렬이라 사실상 상수.

### 구현 포인트
- 정렬하면 확실히 좋음. len_3[2]가 최장인 게 보장되니까 비교가 한 줄로 끝남
- 부등식 깨지면 최장을 (나머지 둘 합 - 1)로 줄이는 게 최선. -1 빠지면 넓이 0짜리 됨
- 짧은 두 놈은 절대 건드리지 마라. 줄이면 둘레만 손해
- 조건 만족하면 그냥 sum 찍고 끝
