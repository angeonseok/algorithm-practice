# 27323.직사각형

## 문제 설명
정수 A, B 가 주어진다.
세로 길이가 A cm, 가로 길이가 B cm 인 아래와 같은 직사각형의 넓이를 cm2 단위로 구하시오.

## 입력
표준 입력에 다음과 같은 형태로 입력이 주어진다.(A \n B)

## 출력
세로 길이가 A cm, 가로 길이가 B cm인 직사각형의 넓이를 cm2 단위로 구하고, 단위 (cm2)를 생략하여 출력한다.

## 풀이 정리

### 핵심 아이디어
세로 가로 받아서 곱하면 끝.

### 시간복잡도
O(1). 곱셈 한 번.

### 구현 포인트
- 입력이 한 줄에 하나씩 내려오니까 split 쓰지 말고 input() 두 번
- 단위(cm2)는 빼고 숫자만 출력
