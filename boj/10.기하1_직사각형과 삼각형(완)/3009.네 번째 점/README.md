# 3009.네 번째 점

## 문제 설명
세 점이 주어졌을 때, 축에 평행한 직사각형을 만들기 위해서 필요한 네 번째 점을 찾는 프로그램을 작성하시오.

## 입력
세 점의 좌표가 한 줄에 하나씩 주어진다.
좌표는 1보다 크거나 같고, 1000보다 작거나 같은 정수이다.

## 출력
직사각형의 네 번째 점의 좌표를 출력한다.

## 풀이 정리

### 핵심 아이디어
축에 평행한 직사각형이라 x값도 y값도 같은 게 2개씩 짝을 짓는다. 주어진 3개 중에 짝 못 찾고 혼자 남은 놈이 네 번째 점 좌표.

### 시간복잡도
O(1). 점이 3개뿐이라 count 돌려도 상수.

### 구현 포인트
- x랑 y를 각각 딴 리스트에 모아야 함. 점 단위로 묶어서 보면 안 보임
- count(x_1[i]) == 1인 놈이 답. x, y 따로 판정해야지 한 점에서 둘 다 나온다는 보장 없다
- 리스트 두 개 만들어놨으면 그 안에서 작업하는 게 편함
