# 24262.수행시간1

## 문제 설명
MenOfPassion(A[], n) {
    i = ⌊n / 2⌋;
    return A[i]; # 코드1
}

## 입력
첫째 줄에 입력의 크기 n(1 ≤ n ≤ 500,000)이 주어진다.

## 출력
첫째 줄에 코드1 의 수행 횟수를 출력한다.
둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수를 출력한다.
단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력한다.

## 풀이 정리

### 핵심 아이디어
코드1이 A[i] 한 번 꺼내고 끝이라 n이 뭐든 수행 횟수는 1. 상수는 n^0이니까 차수 0.

### 시간복잡도
O(1). 출력 두 줄이 전부.

### 구현 포인트
- n을 아예 안 읽어도 통과함. 답이 입력에 안 걸려있음
- 차수 자리에 1 쓰면 틀림. 상수항이라 0이 맞다
