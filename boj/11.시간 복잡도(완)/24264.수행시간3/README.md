## 문제 설명
MenOfPassion(A[], n) {
    sum <- 0;
    for i <- 1 to n
        for j <- 1 to n
            sum <- sum + A[i] × A[j]; # 코드1
    return sum;
}

## 입력
첫째 줄에 입력의 크기 n(1 ≤ n ≤ 500,000)이 주어진다.

## 출력
첫째 줄에 코드1 의 수행 횟수를 출력한다.
둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수를 출력한다.
단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력한다.

## 풀이 정리

### 핵심 아이디어
이중 for가 둘 다 1..n이라 곱하면 n*n. 최고차항이 n^2이니 차수 2.

### 시간복잡도
O(1). n^2번 도는 게 아니라 n^2 값만 찍는 거라 루프 자체가 없음.

### 구현 포인트
- 여긴 n**2 계산해야 되니까 int 변환 빼먹으면 안 됨
- n이 50만이면 값이 2500억까지 가는데 파이썬 정수는 그냥 감당함
