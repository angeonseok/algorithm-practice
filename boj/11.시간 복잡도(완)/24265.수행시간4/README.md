## 문제 설명
MenOfPassion(A[], n) {
    sum <- 0;
    for i <- 1 to n - 1
        for j <- i + 1 to n
            sum <- sum + A[i] × A[j]; # 코드1
    return sum;
}

## 입력
첫째 줄에 입력의 크기 n(1 ≤ n ≤ 500,000)이 주어진다.

## 출력
첫째 줄에 코드1 의 수행 횟수를 출력한다.
둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수를 출력한다.
단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력한다.

## 풀이 정리

### 핵심 아이디어
j가 i+1부터 시작하니까 서로 다른 두 놈 고르는 조합 개수랑 같음. nC2 = n(n-1)/2 박으면 됨.

### 시간복잡도
O(1). 식 한 줄 계산.

### 구현 포인트
- // 로 나눠야지 / 쓰면 실수로 나와서 출력 양식 깨짐. 나눗셈이 문제다 항상
- n(n-1)/2 전개하면 n^2 항이 살아있으니 차수는 2
- n=1이면 0회. 식에 그대로 넣어도 0 나와서 예외처리 안 해도 된다
