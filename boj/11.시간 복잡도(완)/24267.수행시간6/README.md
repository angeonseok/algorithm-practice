## 문제 설명
MenOfPassion(A[], n) {
    sum <- 0;
    for i <- 1 to n - 2
        for j <- i + 1 to n - 1
            for k <- j + 1 to n
                sum <- sum + A[i] × A[j] × A[k]; # 코드1
    return sum;
}

## 입력
첫째 줄에 입력의 크기 n(1 ≤ n ≤ 500,000)이 주어진다.

## 출력
첫째 줄에 코드1 의 수행 횟수를 출력한다.
둘째 줄에 코드1의 수행 횟수를 다항식으로 나타내었을 때, 최고차항의 차수를 출력한다.
단, 다항식으로 나타낼 수 없거나 최고차항의 차수가 3보다 크면 4를 출력한다.

## 풀이 정리

### 핵심 아이디어
삼중 for인데 i < j < k 조건이라 결국 서로 다른 3개 고르는 조합이다. nC3 = n(n-1)(n-2)/6 이고 최고차항은 3차. 예시보면 바로 견적나옴.

### 시간복잡도
O(1). 식 하나 계산하고 끝이라 n이 50만이든 말든 상관없다.

### 구현 포인트
- 삼중 반복문 그대로 돌리면 당연히 터진다. 손으로 nC3 식 뽑아놓고 계산만 하자
- // 로 정수 나눗셈 해야 함. / 쓰면 실수로 나와서 출력양식 깨짐
- 둘째 줄은 그냥 3. 3차식이니까 고민할 게 없다
