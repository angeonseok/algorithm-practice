# 11650.좌표 정렬하기

## 문제 설명
2차원 평면 위의 점 N개가 주어진다. 좌표를 x좌표가 증가하는 순으로, x좌표가 같으면 y좌표가 증가하는 순서로 정렬한 다음 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 점의 개수 N (1 ≤ N ≤ 100,000)이 주어진다. 둘째 줄부터 N개의 줄에는 i번점의 위치 xi와 yi가 주어진다. (-100,000 ≤ xi, yi ≤ 100,000) 좌표는 항상 정수이고, 위치가 같은 두 점은 없다.

## 출력
첫째 줄부터 N개의 줄에 점을 정렬한 결과를 출력한다.

## 풀이 정리

### 핵심 아이디어
x 먼저 보고 같으면 y. [x, y] 리스트로 담아두면 파이썬 기본 sort가 앞항부터 비교해준다. 조건이 그대로라 key도 안 준다.

### 시간복잡도
O(N log N). N 10만, 정렬이 전부다.

### 구현 포인트
- 리스트끼리 비교는 0항 보고 같으면 1항으로 넘어감. key 안 줘도 문제 조건 그대로다
- int로 안 바꾸고 넣으면 문자열 정렬 돼서 10이 2보다 앞으로 온다
- num_list = num_list.sort() 하면 None 박힌다. sort()는 제자리라 걍 호출만
