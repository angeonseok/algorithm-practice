# 1181.단어 정렬

## 문제 설명
알파벳 소문자로 이루어진 N개의 단어가 들어오면 아래와 같은 조건에 따라 정렬하는 프로그램을 작성하시오.
1.길이가 짧은 것부터
2.길이가 같으면 사전 순으로
단, 중복된 단어는 하나만 남기고 제거해야 한다.

## 입력
첫째 줄에 단어의 개수 N이 주어진다. (1 ≤ N ≤ 20,000) 둘째 줄부터 N개의 줄에 걸쳐 알파벳 소문자로 이루어진 단어가 한 줄에 하나씩 주어진다. 주어지는 문자열의 길이는 50을 넘지 않는다.

## 출력
조건에 따라 정렬하여 단어들을 출력한다.

## 풀이 정리

### 핵심 아이디어
중복은 set에 던져서 날리고, 정렬은 (길이, 사전순) 튜플 키 하나로 본다. 조건 2개를 튜플로 묶으면 정렬 한 번에 처리된다.

### 시간복잡도
O(N log N * L). L은 단어 길이(최대 50)라 사전순 비교할 때 붙는다. N이 2만이라 여유.

### 구현 포인트
- set은 순서가 없어서 sort() 메서드가 없다. sorted()로 받아야 함
- key 순서가 (len(x), x). 길이 먼저 보고 같을 때 사전순으로 가른다
- rstrip 안 하면 개행이 단어에 붙어서 길이가 하나씩 밀린다
