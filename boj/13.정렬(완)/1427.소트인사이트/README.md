# 1427.소트인사이트

## 문제 설명
배열을 정렬하는 것은 쉽다. 수가 주어지면, 그 수의 각 자리수를 내림차순으로 정렬해보자.

## 입력
첫째 줄에 정렬하려고 하는 수 N이 주어진다.
N은 1,000,000,000보다 작거나 같은 자연수이다.

## 출력
첫째 줄에 자리수를 내림차순으로 정렬한 수를 출력한다.

## 풀이 정리

### 핵심 아이디어
입력을 숫자가 아니라 문자열로 받고 자릿수 하나씩 리스트에 담아 내림차순 정렬. 한 자리 문자끼리 비교하면 사전순이 곧 크기순이라 그냥 sort 때리면 끝.

### 시간복잡도
O(D log D). D는 자릿수인데 최대 10자리 수준이라 사실상 상수.

### 구현 포인트
- 입력이 2143 이런식으로 붙어서 들어옴. int로 받으면 자릿수 분해부터 다시 해야 하니 문자열로 받자
- sort(reverse=True)로 내림차순
- 출력은 "".join으로 다시 붙이기. 리스트 그대로 print하면 대괄호 나옴
