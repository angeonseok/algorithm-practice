# 18870.좌표 압축

## 문제 설명
수직선 위에 N개의 좌표 X1, X2, ..., XN이 있다. 이 좌표에 좌표 압축을 적용하려고 한다.
Xi를 좌표 압축한 결과 X'i의 값은 Xi > Xj를 만족하는 서로 다른 좌표 Xj의 개수와 같아야 한다.
X1, X2, ..., XN에 좌표 압축을 적용한 결과 X'1, X'2, ..., X'N를 출력해보자.

## 입력
첫째 줄에 N이 주어진다.
둘째 줄에는 공백 한 칸으로 구분된 X1, X2, ..., XN이 주어진다.

## 출력
첫째 줄에 X'1, X'2, ..., X'N을 공백 한 칸으로 구분해서 출력한다.

## 풀이 정리

### 핵심 아이디어
중복 지우고 정렬한 뒤 그 순서를 그대로 등수로 쓴다. 나보다 작은 서로 다른 좌표 개수 = 정렬된 유일값 배열에서 내 인덱스잖.

### 시간복잡도
O(N log N). set 만들고 정렬하는 게 제일 비싸고 나머진 한 번 훑는 거.

### 구현 포인트
- dict(zip(sorted(set(num)), range(...)))로 값 > 등수 매핑을 한 줄에 만듦. 젤 작은 놈부터 0 가진 딕셔너리
- 매번 index()로 찾으면 O(N^2)라 터짐. 딕셔너리 조회로 O(1)
- 출력은 원본 순서 그대로여야 함. 정렬본을 뱉으면 안 됨
