# 25305.커트라인

## 문제 설명
2022 연세대학교 미래캠퍼스 슬기로운 코딩생활에 N명의 학생들이 응시했다.
이들 중 점수가 가장 높은 k명은 상을 받을 것이다. 이 때, 상을 받는 커트라인이 몇 점인지 구하라.
커트라인이란 상을 받는 사람들 중 점수가 가장 가장 낮은 사람의 점수를 말한다.

## 입력
첫째 줄에는 응시자의 수 N과 상을 받는 사람의 수 k가 공백을 사이에 두고 주어진다.
둘째 줄에는 각 학생의 점수 x가 공백을 사이에 두고 주어진다.

## 풀이 정리

### 핵심 아이디어
정렬하고 젤 큰 놈부터 k번째를 집으면 그게 커트라인. 오름차순이면 뒤에서 k번째, 즉 [-k]다.

### 시간복잡도
O(N log N). 정렬 말곤 할 게 없음.

### 구현 포인트
- 괄호 위치 조심. sorted(c)[-b] 여야지 sorted(c[-b])로 쓰면 int 하나를 정렬하려 들어서 터짐
- 내림차순으로 정렬한 뒤 [b-1] 꺼내도 같은 값
- 커트라인은 상 받는 사람 중 최저점이니까 k번째 놈까지 포함이다. 인덱스 하나 밀리기 딱 좋음
