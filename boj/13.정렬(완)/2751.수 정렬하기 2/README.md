# 2751.수 정렬하기 2

## 문제 설명
N개의 수가 주어졌을 때, 이를 오름차순으로 정렬하는 프로그램을 작성하시오.

## 입력
첫째 줄에 수의 개수 N(1 ≤ N ≤ 1,000,000)이 주어진다. 둘째 줄부터 N개의 줄에는 수가 주어진다.
이 수는 절댓값이 1,000,000보다 작거나 같은 정수이다. 수는 중복되지 않는다.

## 출력
첫째 줄부터 N개의 줄에 오름차순으로 정렬한 결과를 한 줄에 하나씩 출력한다.

## 풀이 정리

### 핵심 아이디어
2750이랑 로직은 똑같은데 N이 100만이라 입력을 sys.stdin.readline으로 갈아끼웠다. 리스트 컴프리헨션으로 한 번에 받고 sort.

### 시간복잡도
O(N log N). N은 최대 100만, 파이썬 sort는 팀소트라 충분.

### 구현 포인트
- input() 그대로 쓰면 100만 줄 읽다가 터짐. readline으로 교체하는 게 이 문제의 전부
- 값 범위에 음수가 있어서 카운팅 정렬 하려면 오프셋을 따로 잡아야 함. 걍 sort가 편함
- 출력도 100만 줄이라 print 반복이 좀 아깝다. join으로 묶어서 한 방에 뱉는 게 더 빠름
