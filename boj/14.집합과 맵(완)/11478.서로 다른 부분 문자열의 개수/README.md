# 11478.서로 다른 부분 문자열의 개수

## 문제 설명
문자열 S가 주어졌을 때, S의 서로 다른 부분 문자열의 개수를 구하는 프로그램을 작성하시오.
부분 문자열은 S에서 연속된 일부분을 말하며, 길이가 1보다 크거나 같아야 한다.
예를 들어, ababc의 부분 문자열은 a, b, a, b, c, ab, ba, ab, bc, aba, bab, abc, abab, babc, ababc가 있고, 서로 다른것의 개수는 12개이다.

## 입력
첫째 줄에 문자열 S가 주어진다. S는 알파벳 소문자로만 이루어져 있고, 길이는 1,000 이하이다.

## 출력
첫째 줄에 S의 서로 다른 부분 문자열의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
길이 1000이면 부분 문자열 조각이 50만 개 수준이라 그냥 다 만들어버려도 된다. 이중 for로 슬라이싱해서 리스트에 담고 중복은 set으로 지우고 개수 세기.

### 시간복잡도
O(N^3)에 가까움. N은 문자열 길이. 조각이 N^2개인데 하나 자르고 해싱하는 값이 길이에 또 비례하거든. N이 1000이라 아슬아슬하게 들어감.

### 구현 포인트
- s를 rstrip 안 하고 개행 달린 채로 씀. 그래서 j가 len(s)-1까지만 가도 마지막 글자까지 다 커버됨. 여기서 rstrip 붙이면 끝 글자로 끝나는 조각이 통째로 날아간다
- 리스트에 다 담고 마지막에 set으로 감쌈. 처음부터 set에 add해도 결과는 같고 메모리는 더 아낌
- 길이 1 이상만 세면 되니까 j를 i+1부터 시작
