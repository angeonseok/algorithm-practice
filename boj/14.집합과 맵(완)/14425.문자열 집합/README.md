# 14425.문자열 집합

## 문제 설명
총 N개의 문자열로 이루어진 집합 S가 주어진다. 입력으로 주어지는 M개의 문자열 중에서 집합 S에 포함되어 있는 것이 총 몇 개인지 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 문자열의 개수 N과 M (1 ≤ N ≤ 10,000, 1 ≤ M ≤ 10,000)이 주어진다.
다음 N개의 줄에는 집합 S에 포함되어 있는 문자열들이 주어진다.
다음 M개의 줄에는 검사해야 하는 문자열들이 주어진다.
입력으로 주어지는 문자열은 알파벳 소문자로만 이루어져 있으며, 길이는 500을 넘지 않는다. 집합 S에 같은 문자열이 여러 번 주어지는 경우는 없다.

## 출력
첫째 줄에 M개의 문자열 중에 총 몇 개가 집합 S에 포함되어 있는지 출력한다.

## 풀이 정리

### 핵심 아이디어
집합 S를 set에 넣고 검사할 문자열마다 in 돌려서 카운트. 10815의 문자열 버전이라 보면 된다.

### 시간복잡도
O((N + M) * L). L은 문자열 길이인데 해싱/비교에 그만큼 드는 거고, 조회 횟수 자체는 M번.

### 구현 포인트
- 양쪽 다 rstrip 걸어놨다. 한쪽만 떼면 개행 때문에 비교가 전부 어긋남
- S를 리스트로 두면 문자열 비교를 M*N번 함. set 조회는 해시 한 방이라 이게 포인트
- 검사할 m 쪽은 set으로 안 묶음. 같은 문자열이 또 들어와도 각각 세야 하니까 리스트 그대로 둔다
