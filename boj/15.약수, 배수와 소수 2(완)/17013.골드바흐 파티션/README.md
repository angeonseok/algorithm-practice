# 17013.골드바흐 파티션

## 문제 설명
골드바흐의 추측: 2보다 큰 짝수는 두 소수의 합으로 나타낼 수 있다.
짝수 N을 두 소수의 합으로 나타내는 표현을 골드바흐 파티션이라고 한다.
짝수 N이 주어졌을 때, 골드바흐 파티션의 개수를 구해보자. 두 소수의 순서만 다른 것은 같은 파티션이다.

## 입력
첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있고, 정수 N은 짝수이다.

## 출력
각각의 테스트 케이스마다 골드바흐 파티션의 수를 출력한다.

## 풀이 정리

### 핵심 아이디어
입력값 중 젤 큰 놈까지 에라토스테네스로 소수를 한 번만 만들어놓고, 각 N마다 소수 p를 훑으면서 N - p도 소수인지 본다. 순서만 다른 건 같은 파티션이라 절반만 보면 됨.

### 시간복잡도
O(max_n log log max_n + T * π(max_n / 2)). 체는 한 번만 돌고, 테케마다 소수 리스트를 N/2에서 끊어 훑는 게 실제 비용.

### 구현 포인트
- 테케마다 체 새로 돌리면 낭비라 max(num) 먼저 뽑아놓고 한 방에 생성
- j > i // 2 되면 break. n = p + (n - p) 대칭이라 절반 넘어가면 이미 센 거잖
- 체 배열 p를 판별용으로 그대로 재활용해서 p[i - j] 한 번이면 확인 끝
