# 1934.최소공배수

## 문제 설명
두 자연수 A와 B에 대해서, A의 배수이면서 B의 배수인 자연수를 A와 B의 공배수라고 한다.  이런 공배수 중에서 가장 작은 수를 최소공배수라고 한다.  예를 들어, 6과 15의 공배수는 30, 60, 90등이 있으며, 최소 공배수는 30이다. 두 자연수 A와 B가 주어졌을 때, A와 B의 최소공배수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 테스트 케이스의 개수가 주어진다. 둘째 줄부터 T개의 줄에 걸쳐서 A와 B가 주어진다.

## 출력
첫째 줄부터 T개의 줄에 A와 B의 최소공배수를 입력받은 순서대로 한 줄에 하나씩 출력한다.

## 풀이 정리

### 핵심 아이디어
13241이랑 완전 같은 꼴. gcd 함수 하나 만들어두고 a * b / gcd 반복, 테케가 여러 개라 답은 모았다가 출력.

### 시간복잡도
O(T * log(min(a,b))). T는 테케 수, 케이스마다 호제법 한 번씩.

### 구현 포인트
- gcd 함수는 밖에 빼놓고 테케마다 돌려쓰기
- 13241에서 데였던 그 나눗셈이라 여기선 처음부터 int()로 잘라둠
- ans에 모아놨다가 마지막 루프에서 한꺼번에 찍음
