# 4134.다음 소수

## 문제 설명
정수 n(0 ≤ n ≤ 4*10e9)가 주어졌을 때, n보다 크거나 같은 소수 중 가장 작은 소수 찾는 프로그램을 작성하시오.

## 입력
첫째 줄에 테스트 케이스의 개수가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있고, 정수 n이 주어진다.

## 출력
각각의 테스트 케이스에 대해서 n보다 크거나 같은 소수 중 가장 작은 소수를 한 줄에 하나씩 출력한다.

## 풀이 정리

### 핵심 아이디어
n부터 1씩 올리면서 소수 나올 때까지 뺑이. 범위가 40억이라 체 만들 생각은 버리고 root n까지 나눠보는 판별 함수로 감.

### 시간복잡도
O(T * gap * root n). gap은 n에서 다음 소수까지 거리인데 촘촘해서 몇 번 안 올라가고 걸린다.

### 구현 포인트
- is_prime은 2부터 root m까지만 나눠봄. 상한선 걸어야 안 터짐
- 0이랑 1은 소수 아니니까 맨 앞에서 컷
- n이 40억까지라 에라토스테네스 배열 잡으면 메모리 터짐. 하나씩 판별이 답
