# 10872.팩토리얼

## 문제 설명
0보다 크거나 같은 정수 N이 주어진다. 이때, N!을 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 정수 N(0 ≤ N ≤ 12)이 주어진다.

## 출력
첫째 줄에 N!을 출력한다.

## 풀이 정리

### 핵심 아이디어
1부터 n까지 그냥 곱했다. 재귀도 되는데 굳이.

### 시간복잡도
O(N). N이 12라 뭘 해도 통과.

### 구현 포인트
- 누적 변수 초기값은 1. 0으로 두면 답이 계속 0
- N이 0이면 range가 비어서 1이 그대로 출력됨. 예외처리 따로 안 해도 맞음
