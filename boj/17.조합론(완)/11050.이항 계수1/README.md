# 11050.이항 계수1

## 문제 설명
nCm 계산해보자

## 입력
첫째 줄에 N과 K가 주어진다.

## 출력
nCk

## 풀이 정리

### 핵심 아이디어
팩토리얼 함수 하나 만들어놓고 n! / (k! * (n-k)!) 공식 그대로 박음.

### 시간복잡도
O(N). 팩토리얼 세 번 돌리는 게 다고 N이 작아서 신경 안 써도 됨.

### 구현 포인트
- 나눗셈이 문제다 항상. / 결과가 float라 int()로 다시 씌워야 출력 양식이 맞음
- 재귀 팩토리얼 종료조건은 i == 0일 때 1 반환
