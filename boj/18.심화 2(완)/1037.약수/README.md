# 1037.약수

## 문제 설명
양수 A가 N의 진짜 약수가 되려면, N이 A의 배수이고, A가 1과 N이 아니어야 한다.
어떤 수 N의 진짜 약수가 모두 주어질 때, N을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N의 진짜 약수의 개수가 주어진다. 이 개수는 50보다 작거나 같은 자연수이다.
둘째 줄에는 N의 진짜 약수가 주어진다.
1,000,000보다 작거나 같고, 2보다 크거나 같은 자연수이고, 중복되지 않는다.

## 출력
첫째 줄에 N을 출력한다. N은 항상 32비트 부호있는 정수로 표현할 수 있다.

## 풀이 정리

### 핵심 아이디어
약수는 항상 짝으로 붙어다닌다. 제일 작은 진짜 약수 * 제일 큰 진짜 약수 = N. 그래서 max랑 min만 뽑아서 곱하면 끝.

### 시간복잡도
O(N). 여기서 N은 약수 개수, 많아야 50개다. max 한 번 min 한 번 부르고 끝나서 사실상 상수 취급해도 됨.

### 구현 포인트
- 정렬할 필요도 없다. max() min() 걍 때려박으면 됨
- 첫 줄 약수 개수는 받아만 두고 실제로 안 씀
- 약수 짝 성질만 눈치채면 한 줄 문제
