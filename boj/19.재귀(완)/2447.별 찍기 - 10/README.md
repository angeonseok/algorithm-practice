# 2447.별 찍기 - 10

## 문제 설명
재귀적인 패턴으로 별을 찍어 보자. N이 3의 거듭제곱(3, 9, 27, ...)이라고 할 때, 크기 N의 패턴은 N×N 정사각형 모양이다.
크기 3의 패턴은 가운데에 공백이 있고, 가운데를 제외한 모든 칸에 별이 하나씩 있는 패턴이다.
***
* *
***
N이 3보다 클 경우, 크기 N의 패턴은 공백으로 채워진 가운데의 (N/3)×(N/3) 정사각형을 크기 N/3의 패턴으로 둘러싼 형태이다. 예를 들어 크기 27의 패턴은 예제 출력 1과 같다.

## 입력
첫째 줄에 N이 주어진다. N은 3의 거듭제곱이다. 즉 어떤 정수 k에 대해 N=3k이며, 이때 1 ≤ k < 8이다.

## 출력
첫째 줄부터 N번째 줄까지 별을 출력한다.

## 풀이 정리

### 핵심 아이디어
N*N 공백판 먼저 깔아두고 분할정복으로 별을 찍는다. 한 칸을 9등분해서 가운데만 건너뛰고 나머지 8칸에 재귀.

### 시간복잡도
O(N^2). 판 자체가 N*N이고 재귀는 각 칸을 한 번씩만 건드림.

### 구현 포인트
- 배열 만들었으면 안에서 작업해야지. 문자열 이어붙이기로 하면 지저분해짐
- 재귀에 넘기는 좌표가 r + i*n, c + j*n. 여기서 n은 이미 //3 한 값이라 순서 헷갈리면 박음
- i==1 and j==1일 때만 continue. 가운데는 공백 그대로 두는 거
- 출력은 행마다 join. 한 글자씩 print하면 느림
