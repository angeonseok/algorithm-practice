# 27433.팩토리얼2

## 문제 설명
0보다 크거나 같은 정수 N이 주어진다. 이때, N!을 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 정수 N(0 ≤ N ≤ 20)이 주어진다.

## 출력
첫째 줄에 N!을 출력한다.

## 풀이 정리

### 핵심 아이디어
재귀 정의 그대로. 0이면 1, 아니면 i * fac(i-1).

### 시간복잡도
O(N). N은 20 이하라 재귀 깊이도 20.

### 구현 포인트
- 종료 조건 0! = 1만 잡으면 끝
- 20!이 19자리인데 파이썬은 큰 수 알아서 처리해줌. C++이면 long long 필요
- 반환값이 이미 int인데 print에서 int() 한 번 더 씌워둠. 있어도 그만 없어도 그만
