# 15651.N과 M (3)

## 문제 설명
자연수 N과 M이 주어졌을 때, 아래 조건을 만족하는 길이가 M인 수열을 모두 구하는 프로그램을 작성하시오.
1부터 N까지 자연수 중에서 M개를 고른 수열
같은 수를 여러 번 골라도 된다.

## 입력
첫째 줄에 자연수 N과 M이 주어진다. (1 ≤ M ≤ N ≤ 7)

## 출력
한 줄에 하나씩 문제의 조건을 만족하는 수열을 출력한다. 중복되는 수열을 여러 번 출력하면 안되며, 각 수열은 공백으로 구분해서 출력해야 한다.
수열은 사전 순으로 증가하는 순서로 출력해야 한다.

## 풀이 정리

### 핵심 아이디어
중복순열이다. 같은 수 또 써도 되니까 방문 체크할 이유가 없다. 15649에서 visited만 걷어낸 꼴.

### 시간복잡도
O(N^M * M). N, M이 7까지라 7^7 = 82만 정도, 출력이 더 무겁다.

### 구현 포인트
- 매 깊이마다 1~n 전부 후보. 거를 조건 자체가 없음
- 되돌릴 게 pwr 하나뿐이라 append > 재귀 > pop만 남는다
- N^M이라 개수가 확 튄다. 제한이 7인 게 다행
