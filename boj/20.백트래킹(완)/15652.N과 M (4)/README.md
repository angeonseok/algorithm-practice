# 15652.N과 M (4)

## 문제 설명
자연수 N과 M이 주어졌을 때, 아래 조건을 만족하는 길이가 M인 수열을 모두 구하는 프로그램을 작성하시오.
1부터 N까지 자연수 중에서 M개를 고른 수열
같은 수를 여러 번 골라도 된다.
고른 수열은 비내림차순이어야 한다.
길이가 K인 수열 A가 A1 ≤ A2 ≤ ... ≤ AK-1 ≤ AK를 만족하면, 비내림차순이라고 한다.

## 입력
첫째 줄에 자연수 N과 M이 주어진다. (1 ≤ M ≤ N ≤ 8)

## 출력
한 줄에 하나씩 문제의 조건을 만족하는 수열을 출력한다. 중복되는 수열을 여러 번 출력하면 안되며, 각 수열은 공백으로 구분해서 출력해야 한다.
수열은 사전 순으로 증가하는 순서로 출력해야 한다.

## 풀이 정리

### 핵심 아이디어
중복조합. 15650이랑 딱 한 글자 차이인데 dfs(i+1) 대신 dfs(i)로 자기 자신을 포함시켜서 다시 내려간다.

### 시간복잡도
O(C(N+M-1, M) * M). 비내림차순 수열 개수만큼 도는 거라 N 8에서는 부담 없음.

### 구현 포인트
- dfs(i)라 같은 수를 연달아 고를 수 있고, 결과는 항상 비내림차순으로 나옴
- 자기 자신을 또 부르는데 무한재귀가 안 나는 건 들어가기 전에 cwr을 하나씩 채워서 길이 m에서 끊기기 때문
- 종료 판정을 depth 말고 len(cwr)로 해서 dfs가 start 하나만 들고 다님
