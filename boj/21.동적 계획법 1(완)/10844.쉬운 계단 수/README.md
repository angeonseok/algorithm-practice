# 10844.쉬운 계단 수

## 문제 설명
45656이란 수를 보자.
이 수는 인접한 모든 자리의 차이가 1이다. 이런 수를 계단 수라고 한다.
N이 주어질 때, 길이가 N인 계단 수가 총 몇 개 있는지 구해보자. 0으로 시작하는 수는 계단수가 아니다.

## 입력
첫째 줄에 N이 주어진다. N은 1보다 크거나 같고, 100보다 작거나 같은 자연수이다.

## 출력
첫째 줄에 정답을 1,000,000,000으로 나눈 나머지를 출력한다.

## 풀이 정리

### 핵심 아이디어
자리수를 하나씩 늘리면서 끝자리별 개수를 굴린다. 0은 1로만 갈 수 있고 9는 8로만, 나머지 1~8은 양쪽 둘 다.

### 시간복잡도
O(N * 10) = O(N). N이 100까지라 계산량 자체는 없는 수준.

### 구현 포인트
- s[j]가 끝자리 j로 끝나는 개수. temp에 새로 담고 s = temp로 갈아끼움
- 0으로 시작하는 수는 안 되니까 초기값을 s[0] = 0, 1~9만 1로 깔았다
- dp[i] = sum(s) % mod. 이 나눗셈 빼먹어서 한 번 틀림, 주석에도 박아뒀다
- dp[1] = 9 미리 박아두고 루프는 2부터. n이 1로 들어오면 루프가 아예 안 돈다
