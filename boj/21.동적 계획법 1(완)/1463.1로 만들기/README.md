# 1463.1로 만들기

## 문제 설명
정수 X에 사용할 수 있는 연산은 다음과 같이 세 가지 이다.
X가 3으로 나누어 떨어지면, 3으로 나눈다.
X가 2로 나누어 떨어지면, 2로 나눈다.
1을 뺀다.
정수 N이 주어졌을 때, 위와 같은 연산 세 개를 적절히 사용해서 1을 만들려고 한다. 연산을 사용하는 횟수의 최솟값을 출력하시오.

## 입력
첫째 줄에 1보다 크거나 같고, 106보다 작거나 같은 정수 N이 주어진다.

## 출력
첫째 줄에 연산을 하는 횟수의 최솟값을 출력한다.

## 풀이 정리

### 핵심 아이디어
바텀업으로 2부터 n까지 최소 횟수를 채운다. 일단 1 빼는 경우로 깔아두고 2나 3으로 나눠지면 그쪽이 더 싼지 min으로 비교.

### 시간복잡도
O(N). 2부터 한 바퀴 도는 게 전부고 칸마다 하는 일도 비교 두 번이라 N 100만도 금방.

### 구현 포인트
- dp[i] = dp[i-1] + 1 먼저 깔고, 나눗셈 두 개를 min으로 덮어쓰는 순서가 중요
- 탑다운 재귀로 내려가면 100만 깊이라 위험함. 반복문 바텀업이 안전
- 3부터 나누는 그리디는 반례 있음. 10 같은 놈 넣어보면 바로 깨진다
