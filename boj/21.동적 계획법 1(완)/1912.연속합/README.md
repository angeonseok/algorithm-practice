# 1912.연속합

## 문제 설명
n개의 정수로 이루어진 임의의 수열이 주어진다. 우리는 이 중 연속된 몇 개의 수를 선택해서 구할 수 있는 합 중 가장 큰 합을 구하려고 한다. 단, 수는 한 개 이상 선택해야 한다.
예를 들어서 10, -4, 3, 1, 5, 6, -35, 12, 21, -1 이라는 수열이 주어졌다고 하자. 여기서 정답은 12+21인 33이 정답이 된다.

## 입력
첫째 줄에 정수 n(1 ≤ n ≤ 100,000)이 주어지고 둘째 줄에는 n개의 정수로 이루어진 수열이 주어진다. 수는 -1,000보다 크거나 같고, 1,000보다 작거나 같은 정수이다.

## 출력
첫째 줄에 답을 출력한다.

## 풀이 정리

### 핵심 아이디어
dp[i]를 i번째를 반드시 포함하는 최대 연속합으로 잡았다. 앞 덩어리에 붙일래 여기서 새로 시작할래, 둘 중 큰 놈만 살리고 간다.

### 시간복잡도
O(N). 한 번 훑으면서 dp 채우고 max 한 번. n 10만이면 껌.

### 구현 포인트
- dp[i]가 'i까지의 답'이 아니라 'i를 포함한 합'이라 출력은 dp[n-1]이 아니라 max(dp)
- dp[0] = num[0]으로 시작. 전부 음수여도 하나는 골라야 하니 0으로 두면 안 됨
- dp랑 num 인덱스를 그대로 맞춰놔서 오프셋 계산할 일이 없다
