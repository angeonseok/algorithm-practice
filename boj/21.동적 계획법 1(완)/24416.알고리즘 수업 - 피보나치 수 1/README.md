# 24416.알고리즘 수업 - 피보나치 수 1

## 문제 설명
오늘도 서준이는 동적 프로그래밍 수업 조교를 하고 있다. 아빠가 수업한 내용을 학생들이 잘 이해했는지 문제를 통해서 확인해보자.
오늘은 n의 피보나치 수를 재귀호출과 동적 프로그래밍으로 구하는 알고리즘을 배웠다. 재귀호출에 비해 동적 프로그래밍이 얼마나 빠른지 확인해 보자. 아래 의사 코드를 이용하여 n의 피보나치 수를 구할 경우 코드1 코드2 실행 횟수를 출력하자.
피보나치 수 재귀호출 의사 코드는 다음과 같다.
fib(n) {
    if (n = 1 or n = 2)
    then return 1;  # 코드1
    else return (fib(n - 1) + fib(n - 2));
}
피보나치 수 동적 프로그래밍 의사 코드는 다음과 같다.
fibonacci(n) {
    f[1] <- f[2] <- 1;
    for i <- 3 to n
        f[i] <- f[i - 1] + f[i - 2];  # 코드2
    return f[n];
}

## 입력
첫째 줄에 n(5 ≤ n ≤ 40)이 주어진다.

## 출력
코드1 코드2 실행 횟수를 한 줄에 출력한다.

실제로 fib돌리면 터지는데, 걍 냅둠.

## 풀이 정리

### 핵심 아이디어
풀 게 없다. 문제가 시키는 대로 재귀 fib랑 반복 dp 둘 다 돌리고 카운터만 세면 됨. 재귀는 종료 조건 찍은 횟수, dp는 루프 돈 횟수를 센다.

### 시간복잡도
O(1.618^N). 재귀 쪽이 전부 잡아먹는다. dp는 O(N)이라 말할 것도 없고, n이 40까지라 겨우 버티는 수준.

### 구현 포인트
- f1은 n==1 or n==2 갈 때만 +1, f2는 for 한 바퀴마다 +1. 세는 지점이 서로 다르다
- 반환값은 안 쓰고 호출/대입 횟수만 필요해서 global로 카운터 관리
- 재귀 호출 base 도달 횟수가 곧 fib(n) 값이라 n 커지면 그대로 느려짐
