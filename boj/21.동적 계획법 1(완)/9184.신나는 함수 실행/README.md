# 9184.신나는 함수 실행

## 문제 설명
재귀 호출만 생각하면 신이 난다! 아닌가요?
다음과 같은 재귀함수 w(a, b, c)가 있다.
if a <= 0 or b <= 0 or c <= 0, then w(a, b, c) returns: 1
if a > 20 or b > 20 or c > 20, then w(a, b, c) returns: w(20, 20, 20)
if a < b and b < c, then w(a, b, c) returns:
    w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c)
otherwise it returns:
    w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1)
위의 함수를 구현하는 것은 매우 쉽다. 하지만, 그대로 구현하면 값을 구하는데 매우 오랜 시간이 걸린다. (예를 들면, a=15, b=15, c=15)
a, b, c가 주어졌을 때, w(a, b, c)를 출력하는 프로그램을 작성하시오.

## 입력
입력은 세 정수 a, b, c로 이루어져 있으며, 한 줄에 하나씩 주어진다. 입력의 마지막은 -1 -1 -1로 나타내며, 세 정수가 모두 -1인 경우는 입력의 마지막을 제외하면 없다.

## 출력
입력으로 주어진 각각의 a, b, c에 대해서, w(a, b, c)를 출력한다.

## 풀이 정리

### 핵심 아이디어
지문 그대로 재귀만 돌리면 답이 안 나온다. a, b, c가 전부 20 이하로 잘리니까 21^3 3차원 배열 만들어놓고 계산한 값 캐싱하는 게 전부. 3차원은 뭐야.

### 시간복잡도
O(21^3 + T). T는 질문 수. 상태가 9261개뿐이라 한 번 채워두면 그 다음부턴 쿼리당 O(1).

### 구현 포인트
- 0 이하 체크랑 20 초과 체크를 캐시 조회보다 위에 둬야 한다. 순서 바뀌면 배열 범위 밖으로 나가서 터짐
- 20 넘는 놈은 무조건 w(20,20,20)으로 보내버림. 얘 하나만 계산되면 나머진 다 재활용
- dp[a][b][c]가 0인지로 계산 여부를 판별. w 결과가 0이 되는 경우가 없어서 그냥 통함
- 입력은 -1 -1 -1 나올 때까지 while로 계속 받고, 출력 양식은 f-string으로 맞춤
