# 9251.LCS

## 문제 설명
LCS(Longest Common Subsequence, 최장 공통 부분 수열)문제는 두 수열이 주어졌을 때, 모두의 부분 수열이 되는 수열 중 가장 긴 것을 찾는 문제이다.
예를 들어, ACAYKP와 CAPCAK의 LCS는 ACAK가 된다.

## 입력
첫째 줄과 둘째 줄에 두 문자열이 주어진다. 문자열은 알파벳 대문자로만 이루어져 있으며, 최대 1000글자로 이루어져 있다.

## 출력
첫째 줄에 입력으로 주어진 두 문자열의 LCS의 길이를 출력한다.

## 풀이 정리

### 핵심 아이디어
두 문자열을 행/열로 놓고 이차원 표를 채운다. 문자가 같으면 대각선 값에 +1, 다르면 위랑 왼쪽 중 큰 놈 가져오기.

### 시간복잡도
O(N*M). 두 문자열 길이. 최대 1000*1000이라 100만 칸, 그냥 돌아간다.

### 구현 포인트
- 행이 str2, 열이 str1이다. 비교할 땐 str1[j-1] 과 str2[i-1] 로 한 칸 당겨야 함. 인덱스를 잘 생각하자, 한 번 틀렸다
- 0행 0열은 패딩용으로 비워두려고 크기를 len+1 로 잡음
- 답은 표 오른쪽 아래 끝인 dp[m-1][n-1]
- 헷갈려서 예시 행렬을 주석에 직접 그려놓고 맞춰봤다
