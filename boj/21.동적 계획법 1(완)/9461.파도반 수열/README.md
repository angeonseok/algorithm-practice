# 9461.파도반 수열

## 문제 설명
오른쪽 그림과 같이 삼각형이 나선 모양으로 놓여져 있다. 첫 삼각형은 정삼각형으로 변의 길이는 1이다. 그 다음에는 다음과 같은 과정으로 정삼각형을 계속 추가한다. 나선에서 가장 긴 변의 길이를 k라 했을 때, 그 변에 길이가 k인 정삼각형을 추가한다.
파도반 수열 P(N)은 나선에 있는 정삼각형의 변의 길이이다. P(1)부터 P(10)까지 첫 10개 숫자는 1, 1, 1, 2, 2, 3, 4, 5, 7, 9이다.
N이 주어졌을 때, P(N)을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있고, N이 주어진다. (1 ≤ N ≤ 100)

## 출력
각 테스트 케이스마다 P(N)을 출력한다.

## 풀이 정리

### 핵심 아이디어
삼각형 붙여나가는 규칙 보면 p[i] = p[i-1] + p[i-5] 가 나온다. 식만 나오면 그 뒤론 볼 게 없음.

### 시간복잡도
O(T * N). T는 테스트케이스 수, N은 100 이하. 뭘 해도 통과한다.

### 구현 포인트
- p[1]~p[5] = 1,1,1,2,2 초기값이 전부다. 여기 하나 틀어지면 뒤가 다 어긋남
- a가 5보다 작게 들어올 수 있다. 초기값 대입을 if로 하나씩 끊어놔야 인덱스가 안 튄다
- 테케마다 배열을 새로 만든다. 100까지 미리 채워놓고 재사용해도 되는데 걍 다시 돌림
