# 2559.수열

## 문제 설명
매일 아침 9시에 학교에서 측정한 온도가 어떤 정수의 수열로 주어졌을 때, 연속적인 며칠 동안의 온도의 합이 가장 큰 값을 알아보고자 한다.
예를 들어, 아래와 같이 10일 간의 온도가 주어졌을 때,
3 -2 -4 -9 0 3 7 13 8 -3
모든 연속적인 이틀간의 온도의 합은 아래와 같다.
(알아서 계산)
이때, 온도의 합이 가장 큰 값은 21이다.
또 다른 예로 위와 같은 온도가 주어졌을 때, 모든 연속적인 5일 간의 온도의 합은 아래와 같으며,
(알아서 계산)
이때, 온도의 합이 가장 큰 값은 31이다.
매일 측정한 온도가 정수의 수열로 주어졌을 때, 연속적인 며칠 동안의 온도의 합이 가장 큰 값을 계산하는 프로그램을 작성하시오.

## 입력
첫째 줄에는 두 개의 정수 N과 K가 한 개의 공백을 사이에 두고 순서대로 주어진다. 첫 번째 정수 N은 온도를 측정한 전체 날짜의 수이다. N은 2 이상 100,000 이하이다. 두 번째 정수 K는 합을 구하기 위한 연속적인 날짜의 수이다. K는 1과 N 사이의 정수이다. 둘째 줄에는 매일 측정한 온도를 나타내는 N개의 정수가 빈칸을 사이에 두고 주어진다. 이 수들은 모두 -100 이상 100 이하이다.

## 출력
첫째 줄에는 입력되는 온도의 수열에서 연속적인 K일의 온도의 합이 최대가 되는 값을 출력한다.

## 풀이 정리

### 핵심 아이디어
연속 K일 합은 누적합 두 개의 차다. 걍 이중 for 뇌빼고 돌렸다 터져서 누적합으로 갈아엎음.

### 시간복잡도
O(N). N은 날짜 수. 누적합 만들 때 한 번, 구간 훑을 때 한 번 지나가는 게 전부.

### 구현 포인트
- prefix는 1-indexed로 잡아야 i-1 접근에서 예외 안 남
- sub[i] = prefix[i+k] - prefix[i]. 배열 길이가 n-k+1이라 range 범위 조심
- 온도가 음수도 나오니까 max 초기값을 0으로 잡으면 안 됨. 그래서 배열 만들고 max 돌림
