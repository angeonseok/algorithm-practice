# 11401.이항 계수 3

## 문제 설명
자연수 N과 정수 K가 주어졌을 때 이항계수 nCk를 1,000,000,007로 나눈 나머지를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N과 K 가 주어진다. (1 ≤ N ≤ 4,000,000, 0 ≤ K ≤ N)

## 출력
nCk를 1,000,000,007로 나눈 나머지를 출력한다.

## 풀이 정리

### 핵심 아이디어
팩토리얼을 미리 다 깔아두고 분모는 나누는 대신 모듈러 역원을 곱한다. mod가 소수라 페르마 소정리로 a^(mod-2)가 곧 역원이 되는 걸 써먹음.

### 시간복잡도
O(N + log mod). N은 팩토리얼 만드는 400만 번, 역원 구하는 건 분할정복 거듭제곱이라 log.

### 구현 포인트
- mod 연산에 나눗셈이 없으니 분모 r!(n-r)! 을 mod-2 제곱해서 역원으로 바꿔 곱함
- 조합 생성 자체가 불가능한 r<0, r>n은 들어오자마자 0으로 컷
- 거듭제곱은 짝/홀 나눠서 반갈. 매 단계 mod 안 걸면 수가 감당이 안 됨
- 역원 구할 때 fact[r]*fact[n-r] 를 통째로 한 번만 태움. 따로따로 두 번 돌릴 이유가 없다
