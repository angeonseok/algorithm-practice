# 1629.곱셈

## 문제 설명
자연수 A를 B번 곱한 수를 알고 싶다. 단 구하려는 수가 매우 커질 수 있으므로 이를 C로 나눈 나머지를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 A, B, C가 빈 칸을 사이에 두고 순서대로 주어진다. A, B, C는 모두 2,147,483,647 이하의 자연수이다.

## 출력
첫째 줄에 A를 B번 곱한 수를 C로 나눈 나머지를 출력한다.

## 풀이 정리

### 핵심 아이디어
C^n = C^(n/2) * C^(n/2) 로 반갈해서 내려가는 분할정복 거듭제곱. B가 21억이라 그냥 곱하면 터진다.

### 시간복잡도
O(log B). 지수를 매번 반으로 접으니까 재귀 깊이가 log B.

### 구현 포인트
- 숫자 크게 곱하면 터져서 매 계산마다 나눔
- b==0이면 1이 아니라 1 % c 를 반환. c가 1이면 0이 나와야 하니까
- 홀수는 (b-1)//2로 내려간 다음 마지막에 a를 한 번 더 곱해줌
