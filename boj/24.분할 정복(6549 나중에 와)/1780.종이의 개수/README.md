# 1780.종이의 개수

## 문제 설명
N×N크기의 행렬로 표현되는 종이가 있다. 종이의 각 칸에는 -1, 0, 1 중 하나가 저장되어 있다. 우리는 이 행렬을 다음과 같은 규칙에 따라 적절한 크기로 자르려고 한다.
1. 만약 종이가 모두 같은 수로 되어 있다면 이 종이를 그대로 사용한다.
2 .(1)이 아닌 경우에는 종이를 같은 크기의 종이 9개로 자르고, 각각의 잘린 종이에 대해서 (1)의 과정을 반복한다.
이와 같이 종이를 잘랐을 때, -1로만 채워진 종이의 개수, 0으로만 채워진 종이의 개수, 1로만 채워진 종이의 개수를 구해내는 프로그램을 작성하시오.

## 입력
첫째 줄에 N(1 ≤ N ≤ 3^7, N은 3^k 꼴)이 주어진다. 다음 N개의 줄에는 N개의 정수로 행렬이 주어진다.

## 출력
첫째 줄에 -1로만 채워진 종이의 개수를, 둘째 줄에 0으로만 채워진 종이의 개수를, 셋째 줄에 1로만 채워진 종이의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
재귀로 9등분하면서 내려간다. 구간이 전부 같은 수면 그 자리에서 세고 컷, 하나라도 다르면 3x3으로 쪼개서 또 내려감.

### 시간복잡도
O(N^2 log N). N은 한 변 길이(3^7). 깊이마다 전체를 한 번씩 훑는 셈이라 이렇게 잡힌다.

### 구현 포인트
- 첫 칸 값을 기준으로 잡고 구간을 전부 비교. 다른 놈 하나 나오는 순간 9등분 돌리고 바로 return 해야 아래 카운팅으로 안 흘러감
- 나눌때 가로 > 세로 순으로 잘 하자. dx, dy에 n//3 곱해서 시작 좌표 만듦
- 카운터 a, b, c는 global로 빼서 재귀 안에서 누적시킴
- 출력은 -1, 0, 1 순서라 sep='\n' 로 세 줄 떨궈줌
