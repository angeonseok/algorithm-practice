# 6549.히스토그램에서 가장 큰 직사각형

## 문제 설명
히스토그램은 직사각형 여러 개가 아래쪽으로 정렬되어 있는 도형이다. 각 직사각형은 같은 너비를 가지고 있지만, 높이는 서로 다를 수도 있다.
히스토그램에서 가장 넓이가 큰 직사각형을 구하는 프로그램을 작성하시오.

## 입력
입력은 테스트 케이스 여러 개로 이루어져 있다. 각 테스트 케이스는 한 줄로 이루어져 있고, 직사각형의 수 n이 가장 처음으로 주어진다. (1 ≤ n ≤ 100,000) 그 다음 n개의 정수 h1, ..., hn (0 ≤ hi ≤ 1,000,000,000)가 주어진다. 이 숫자들은 히스토그램에 있는 직사각형의 높이이며, 왼쪽부터 오른쪽까지 순서대로 주어진다. 모든 직사각형의 너비는 1이고, 입력의 마지막 줄에는 0이 하나 주어진다.

## 출력
각 테스트 케이스에 대해서, 히스토그램에서 가장 넓이가 큰 직사각형의 넓이를 출력한다.

## 풀이 정리

### 핵심 아이디어
어 일단 스택으로 했어. 각 막대가 왼쪽으로 어디까지 뻗을 수 있나를 스택으로 물고 다니면서 넓이를 갱신한다. 분할정복 아이디어 떠오르면 다시 올 예정.

### 시간복잡도
O(N). 막대 하나가 스택에 한 번 들어갔다 한 번 나오는 게 전부라 테케 하나당 선형. 테케 여러 개면 그만큼 더 돈다.

### 구현 포인트
- arr[0]이 n이고 높이는 arr[1..n]에 들어있다. 인덱스 한 칸 밀린 거 조심
- 지금 높이보다 큰 놈들 pop 하면서 그놈의 시작점 start를 물려받는다. 이게 왼쪽으로 확장되는 구간
- 루프 끝나고 스택에 남은 놈들은 오른쪽 끝까지 뻗는 거라 (n - a + 1) 폭으로 계산
- 높이가 10억이라 넓이가 커진다. 파이썬이라 오버플로 걱정은 안 해도 됨
