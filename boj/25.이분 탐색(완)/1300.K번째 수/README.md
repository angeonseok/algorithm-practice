# 1300.K번째 수

## 문제 설명
세준이는 크기가 N*N인 배열 A를 만들었다. 배열에 들어있는 수 A[i][j] = i*j 이다. 이 수를 일차원 배열 B에 넣으면 B의 크기는 N*N이 된다. B를 오름차순 정렬했을 때, B[k]를 구해보자.
배열 A와 B의 인덱스는 1부터 시작한다.

## 입력
첫째 줄에 배열의 크기 N이 주어진다. N은 105보다 작거나 같은 자연수이다. 둘째 줄에 k가 주어진다. k는 min(109, N2)보다 작거나 같은 자연수이다.

## 출력
B[k]를 출력한다.

## 풀이 정리

### 핵심 아이디어
B를 실제로 만들면 N^2라 터진다. 배열 말고 답 값 자체를 이분탐색하는 걸로 관점을 틀었다. mid 이하 원소가 몇 개인지만 셀 수 있으면 됨.

### 시간복잡도
O(N log K). mid 잡을 때마다 N개 행을 훑고 k가 최대 10^9라 log가 30쯤.

### 구현 포인트
- i행은 i, 2i, 3i, ... 라서 mid 이하 개수가 mid // i개. 근데 한 행에 최대 n개라 min(mid // i, n)로 자름
- cnt >= k면 답 후보 저장하고 왼쪽으로 좁힌다. 이래야 답이 배열에 실제로 있는 값으로 떨어짐
- 탐색 범위는 1부터 k까지. B[k]가 k를 넘을 수 없잖
