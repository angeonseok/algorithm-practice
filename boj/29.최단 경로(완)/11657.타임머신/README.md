# 11657.타임머신

## 문제 설명
N개의 도시가 있다. 그리고 한 도시에서 출발하여 다른 도시에 도착하는 버스가 M개 있다. 각 버스는 A, B, C로 나타낼 수 있는데, A는 시작도시, B는 도착도시, C는 버스를 타고 이동하는데 걸리는 시간이다. 시간 C가 양수가 아닌 경우가 있다. C = 0인 경우는 순간 이동을 하는 경우, C < 0인 경우는 타임머신으로 시간을 되돌아가는 경우이다.
1번 도시에서 출발해서 나머지 도시로 가는 가장 빠른 시간을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 도시의 개수 N (1 ≤ N ≤ 500), 버스 노선의 개수 M (1 ≤ M ≤ 6,000)이 주어진다. 둘째 줄부터 M개의 줄에는 버스 노선의 정보 A, B, C (1 ≤ A, B ≤ N, -10,000 ≤ C ≤ 10,000)가 주어진다.

## 출력
만약 1번 도시에서 출발해 어떤 도시로 가는 과정에서 시간을 무한히 오래 전으로 되돌릴 수 있다면 첫째 줄에 -1을 출력한다. 그렇지 않다면 N-1개 줄에 걸쳐 각 줄에 1번 도시에서 출발해 2번 도시, 3번 도시, ..., N번 도시로 가는 가장 빠른 시간을 순서대로 출력한다. 만약 해당 도시로 가는 경로가 없다면 대신 -1을 출력한다.

## 풀이 정리

### 핵심 아이디어
음수 간선이 존재하는 경우, 다익스트라는 최단거리 보장이 안 됨. 벨만 포드로 v-1번 완화하고 한 번 더 돌려서 음수 사이클을 잡는다.

### 시간복잡도
O(N * M). 500 * 6000이면 300만이고, 변화 없는 라운드에서 끊어버려서 실제론 더 일찍 끝난다.

### 구현 포인트
- 완화 다 했는데 또 줄어? > 음수인 사이클 존재. 그때 -1 뱉고 끝
- dist[u]가 INF인 간선은 건드리면 안 됨. 안 막으면 못 가는 도시에서 음수 더해서 줄어든 걸로 착각함
- 라운드 돌았는데 update가 없으면 break. 안 넣어도 정답이지만 시간이 아깝잖
- 음수 사이클 -1이랑 도달 불가 -1이 같은 글자라 헷갈리는데 판정 위치가 다르다
