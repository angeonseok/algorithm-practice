# 1450.냅색문제

## 문제 설명
세준이는 N개의 물건을 가지고 있고, 최대 C만큼의 무게를 넣을 수 있는 가방을 하나 가지고 있다.
N개의 물건을 가방에 넣는 방법의 수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N과 C가 주어진다. N은 30보다 작거나 같은 자연수, C는 109보다 작거나 같은 음이 아닌 정수이다. 둘째 줄에 물건의 무게가 주어진다. 무게도 109보다 작거나 같은 자연수이다.

## 출력
첫째 줄에 가방에 넣는 방법의 수를 출력한다.

## 풀이 정리

### 핵심 아이디어
N이 30이라 2^30을 전부 보는 건 무리. 반으로 쪼개서 양쪽 부분집합 합을 따로 다 만들고(2^15씩), 왼쪽 값 하나마다 오른쪽에서 c - x 이하인 개수를 이분탐색으로 세는 식으로 갔다.

### 시간복잡도
O(2^(N/2) * N). 반쪽마다 부분합이 2^15 = 3만 개 남짓이고, 정렬이랑 bisect에 붙는 log가 결국 N/2 수준이라 다 합쳐도 이 정도.

### 구현 포인트
- combinations를 길이 0부터 돌려서 공집합(합 0)도 넣어야 아무것도 안 담는 경우가 세짐
- 오른쪽만 정렬해두면 bisect_right로 c - x 이하 개수가 바로 나온다. 왼쪽은 그냥 한 번 훑기만 하니까 정렬 안 해도 ㄱㅊ
- c - x가 음수여도 bisect가 알아서 0 뱉으니 예외처리 따로 안 함
