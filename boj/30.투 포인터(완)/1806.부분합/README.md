# 1806.부분합

## 문제 설명
10,000 이하의 자연수로 이루어진 길이 N짜리 수열이 주어진다. 이 수열에서 연속된 수들의 부분합 중에 그 합이 S 이상이 되는 것 중, 가장 짧은 것의 길이를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N (10 ≤ N < 100,000)과 S (0 < S ≤ 100,000,000)가 주어진다. 둘째 줄에는 수열이 주어진다. 수열의 각 원소는 공백으로 구분되어져 있으며, 10,000이하의 자연수이다.

## 출력
첫째 줄에 구하고자 하는 최소의 길이를 출력한다. 만일 그러한 합을 만드는 것이 불가능하다면 0을 출력하면 된다.

## 풀이 정리

### 핵심 아이디어
합이 s 이상인 구간 중 제일 짧은 걸 찾는 거라 투 포인터. r 밀어서 합 채우고, s 넘어가면 l 당기면서 길이를 갱신하는 구조.

### 시간복잡도
O(N). l이랑 r이 각각 끝까지 한 번씩만 가니까 합쳐도 2N.

### 구현 포인트
- 안쪽은 while이어야 한다. if로 하면 한 칸만 줄이고 나와서 최소 길이가 안 나옴
- r을 이미 증가시킨 뒤라 구간 길이가 r - l 그대로임. 인덱스 조심
- ans를 큰 수로 박아두고 끝나서도 그대로면 못 만든 거니까 0 출력
