# 3273.두 수의 합

## 문제 설명
n개의 서로 다른 양의 정수 a1, a2, ..., an으로 이루어진 수열이 있다. ai의 값은 1보다 크거나 같고, 1000000보다 작거나 같은 자연수이다. 자연수 x가 주어졌을 때, ai + aj = x (1 ≤ i < j ≤ n)을 만족하는 (ai, aj)쌍의 수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 수열의 크기 n이 주어진다. 다음 줄에는 수열에 포함되는 수가 주어진다. 셋째 줄에는 x가 주어진다. (1 ≤ n ≤ 100000, 1 ≤ x ≤ 2000000)

## 출력
문제의 조건을 만족하는 쌍의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
정렬하고 양 끝에서 중앙으로 모는 기본 투 포인터. 크게 더한 쪽을 줄이고 작게 더한 쪽을 늘리면 끝.

### 시간복잡도
O(N log N). 정렬 빼면 포인터가 n을 한 번 훑고 종료.

### 구현 포인트
- 합이 딱 맞으면 l, r 둘 다 움직여야 같은 쌍을 또 세지 않음
- 수가 전부 서로 다르다는 조건이라 중복 값 처리는 신경 안 써도 됨
- 정렬 안 하고 시작하면 양 끝 포인터 논리가 통째로 깨진다. 입력받자마자 sorted로 감싸놓음
