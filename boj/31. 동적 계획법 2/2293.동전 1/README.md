# 2293.동전 1

## 문제 설명
n가지 종류의 동전이 있다. 각각의 동전이 나타내는 가치는 다르다. 이 동전을 적당히 사용해서, 그 가치의 합이 k원이 되도록 하고 싶다. 그 경우의 수를 구하시오. 각각의 동전은 몇 개라도 사용할 수 있다.
사용한 동전의 구성이 같은데, 순서만 다른 것은 같은 경우이다.

## 입력
첫째 줄에 n, k가 주어진다. (1 ≤ n ≤ 100, 1 ≤ k ≤ 10,000) 다음 n개의 줄에는 각각의 동전의 가치가 주어진다. 동전의 가치는 100,000보다 작거나 같은 자연수이다.

## 출력
첫째 줄에 경우의 수를 출력한다. 경우의 수는 2^31보다 작다.

## 풀이 정리

### 핵심 아이디어
동전을 바깥 루프, 금액을 안쪽 루프로 두는 냅색. 순서만 다른 건 같은 경우로 치니까 동전이 바깥에 있어야 조합으로 세진다.

### 시간복잡도
O(N*K). 동전 100개 * 금액 1만 = 100만이라 그냥 돌려도 됨.

### 구현 포인트
- dp[0] = 1. 동전을 안 쓰는 1가지 경우만 있음
- i-a원을 만드는 방법에 지금 동전을 하나 붙이는 느낌으로 dp[i] += dp[i-a]
- 동전을 배열에 모아둘 필요가 없더라. 하나 받자마자 바로 dp 갱신하고 버림
- 루프 순서를 뒤집으면 순열로 세져서 답이 뻥튀기됨. 순서 조심
