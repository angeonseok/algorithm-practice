# 9252.LCS 2

## 문제 설명
LCS(Longest Common Subsequence, 최장 공통 부분 수열)문제는 두 수열이 주어졌을 때, 모두의 부분 수열이 되는 수열 중 가장 긴 것을 찾는 문제이다.
예를 들어, ACAYKP와 CAPCAK의 LCS는 ACAK가 된다.

## 입력
첫째 줄과 둘째 줄에 두 문자열이 주어진다. 문자열은 알파벳 대문자로만 이루어져 있으며, 최대 1000글자로 이루어져 있다.

## 출력
첫째 줄에 입력으로 주어진 두 문자열의 LCS의 길이를, 둘째 줄에 LCS를 출력한다.
LCS가 여러 가지인 경우에는 아무거나 출력하고, LCS의 길이가 0인 경우에는 둘째 줄을 출력하지 않는다.

## 풀이 정리

### 핵심 아이디어
LCS dp 다 채워놓고 (m, n)에서 거꾸로 내려오며 문자열을 복원한다. trace 배열 따로 안 만들고 dp 값 자체를 역산하면 돼서 편함.

### 시간복잡도
O(NM). N, M은 두 문자열 길이 각 1000이라 백만 칸. 복원은 길어야 N+M번 이동.

### 구현 포인트
- 두 글자가 같으면 대각위치값 +1, 아니면 위나 왼쪽 중 큰 값
- 역추적도 같은 규칙 뒤집기. 글자 같으면 답에 넣고 대각선, 아니면 dp[i-1][j] > dp[i][j-1] 큰 쪽으로만 이동
- i는 s2, j는 s1 인덱스라 헷갈린다. 인덱스 조심
- ans는 뒤에서부터 쌓이니 [::-1]로 뒤집어서 join
