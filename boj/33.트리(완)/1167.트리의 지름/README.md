# 1167.트리의 지름

## 문제 설명
트리의 지름이란, 트리에서 임의의 두 점 사이의 거리 중 가장 긴 것을 말한다. 트리의 지름을 구하는 프로그램을 작성하시오.

## 입력
트리가 입력으로 주어진다. 먼저 첫 번째 줄에서는 트리의 정점의 개수 V가 주어지고 (2 ≤ V ≤ 100,000)둘째 줄부터 V개의 줄에 걸쳐 간선의 정보가 다음과 같이 주어진다. 정점 번호는 1부터 V까지 매겨져 있다.
먼저 정점 번호가 주어지고, 이어서 연결된 간선의 정보를 의미하는 정수가 두 개씩 주어지는데, 하나는 정점번호, 다른 하나는 그 정점까지의 거리이다. 예를 들어 네 번째 줄의 경우 정점 3은 정점 1과 거리가 2인 간선으로 연결되어 있고, 정점 4와는 거리가 3인 간선으로 연결되어 있는 것을 보여준다. 각 줄의 마지막에는 -1이 입력으로 주어진다. 주어지는 거리는 모두 10,000 이하의 자연수이다.

## 출력
첫째 줄에 트리의 지름을 출력한다.

## 풀이 정리

### 핵심 아이디어
아무 노드에서 bfs 한 번 돌려 제일 먼 놈 찾고, 그 놈 기준으로 또 bfs 돌린 최대 거리가 지름. 두 번 돌리면 끝나는 그 방법.

### 시간복잡도
O(V). V는 정점 수 10만. bfs 두 번이라 상수만 2배.

### 구현 포인트
- 입력이 정점번호 뒤에 (연결정점, 거리) 쌍이 반복되고 -1로 끝나는 형태. pop()으로 -1 떼고 2칸씩 건너뛰며 파싱
- visited에 (간선수, 누적거리)로 저장했는데 지금 보니까 간선 수는 필요없어 보인다. 걍 지워도 될 듯
- visited -1이 미방문 표시라 제일 먼 놈 고를 때 -1은 continue로 걸러야 함
- 정답은 두 번째 bfs의 거리값. 첫 bfs의 거리는 버려도 된다
