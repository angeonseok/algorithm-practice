# 11725.트리의 부모 찾기

## 문제 설명
루트 없는 트리가 주어진다. 이때, 트리의 루트를 1이라고 정했을 때, 각 노드의 부모를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 노드의 개수 N (2 ≤ N ≤ 100,000)이 주어진다. 둘째 줄부터 N-1개의 줄에 트리 상에서 연결된 두 정점이 주어진다.

## 출력
첫째 줄부터 N-1개의 줄에 각 노드의 부모 노드 번호를 2번 노드부터 순서대로 출력한다.

## 풀이 정리

### 핵심 아이디어
루트를 1로 박아놓고 bfs로 퍼져나가면 처음 만나게 해준 놈이 곧 부모다. 간선을 양방향으로 넣어도 방문 체크가 방향을 정해줌.

### 시간복잡도
O(N). N은 노드 수 10만. 간선 N-1개를 한 번씩 훑는 게 전부.

### 구현 포인트
- bfs로 순회하면서 a의 자식들 체크 > 자식들의 자식 체크 이런 식으로 내려감
- 간선 입력이 부모 자식 순서가 아니라서 양방향으로 다 넣어야 한다
- p[0], p[1]은 0으로 남으니까 출력할 때 0인 건 건너뛰면 2번부터 깔끔하게 나옴
- dfs 재귀로도 되는데 n이 10만이라 bfs가 마음 편하다
