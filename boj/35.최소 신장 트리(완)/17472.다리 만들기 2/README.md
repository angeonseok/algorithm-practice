# 17472.다리 만들기 2

## 문제 설명
섬을 번호로 구분하고, 만들 수 있는 다리를 간선으로 변환한 뒤 모든 섬을 최소 비용으로 연결하는 문제입니다.

## 풀이 파일

- `17472.다리 만들기 2(kruskal).py`: 가능한 다리를 간선 목록으로 만든 뒤 Kruskal 알고리즘으로 MST를 구성합니다.
- `17472.다리 만들기 2(prim).py`: 가능한 다리를 인접 정보로 만든 뒤 Prim 알고리즘으로 MST를 구성합니다.

## 풀이 정리

### 핵심 아이디어
bfs로 섬마다 번호부터 박고, 각 칸에서 네 방향으로 직선으로 쭉 밀어서 길이 2 이상 나오는 놈만 간선으로 만든 다음 그 간선들로 MST를 돌린다.

### 시간복잡도
O(N*M*(N+M) + E log E). 칸마다 네 방향 직선 탐색이 제일 비싸고, 섬이 최대 6개라 간선 수는 얼마 안 됨.

### 구현 포인트
- 다리 길이 2 미만은 무효고, 직선 밀다가 자기 섬 다시 만나거나 다른 섬에 닿으면 거기서 컷
- 같은 섬 쌍이 여러 번 나오니까 (min, max) 키 딕셔너리로 제일 짧은 놈만 남기고 그래프로 변환
- 섬 번호를 2부터 매겨서 prim 시작 정점도 2로 맞춤. 여기 안 맞추면 그냥 0 나옴
- prim이 리턴하는 cnt는 연결된 정점 수라 i_cnt랑 다르면 -1. 참고로 (kruskal).py랑 (prim).py 내용이 지금 똑같다, 둘 다 프림
