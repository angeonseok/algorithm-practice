# 30618.donstructive

## 문제 설명
순열은 1부터 N까지 N개의 정수가 각각 한 번씩 나오는 수열이다. 예를 들어, [1], [3, 5, 2, 1, 4], [1, 3, 2]는 순열이지만, [2, 3, 2], [4, 3, 1], [0]은 순열이 아니다.
순열의 점수는 다음과 같은 방법으로 구한다.
순열의 모든 연속 부분 수열 각각에 대해 원소의 합을 구한다.
순열의 점수는 (1)에서 구한 모든 값의 합이다.
길이가 N인 모든 순열 중에서 점수가 가장 높은 순열을 구해보자. 점수가 가장 높은 순열이 여러 가지라면 그 중 아무거나 하나를 출력한다.

## 입력
첫째 줄에 구하고자 하는 순열의 길이 N이 주어진다. (1 ≤ N ≤ 200000)

## 출력
첫째 줄에 점수가 가장 높은 순열에 해당하는 N개의 정수를 공백으로 구분해서 출력한다.

## 풀이 정리

### 핵심 아이디어
i번 자리 숫자가 답에 몇 번 더해지는지 세보면 i * (n-i+1) 이라 가운데일수록 세게 먹는다. 그럼 큰 놈을 가운데로 몰면 되지. 홀수 오름차순 깔고 짝수 내림차순 붙이면 알아서 산 모양 나옴.

### 시간복잡도
O(N). N은 순열 길이. range 두 개 만들고 하나 뒤집어서 출력하는 게 전부라 계산이랄 것도 없다.

### 구현 포인트
- 가중치가 i * (n-i+1) 인 걸 손으로 좀 적어보면 견적 나옴. 가운데가 제일 크다
- 정렬 필요 없다. 1,3,5,... 이어서 ...,6,4,2 붙이면 그게 이미 산 모양
- 답이 여러 개면 아무거나 내면 되는 문제라 좌우 뒤집어도 점수 똑같다
- N이 20만이라 print(*리스트) 로 한 방에 뱉어야지 한 줄씩 찍으면 터짐
