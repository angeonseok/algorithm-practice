# 2166.다각형의 면적

## 문제 설명
2차원 평면상에 N(3 ≤ N ≤ 10,000)개의 점으로 이루어진 다각형이 있다. 이 다각형의 면적을 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N이 주어진다. 다음 N개의 줄에는 다각형을 이루는 순서대로 N개의 점의 x, y좌표가 주어진다. 좌표값은 절댓값이 100,000을 넘지 않는 정수이다.

## 출력
첫째 줄에 면적을 출력한다. 면적을 출력할 때에는 소수점 아래 둘째 자리에서 반올림하여 첫째 자리까지 출력한다.

## 풀이 정리

### 핵심 아이디어
신발끈 공식 그대로 박았다. 좌표를 어긋나게 곱해서 두 방향 합을 빼고 절댓값에 0.5 곱하면 면적.

### 시간복잡도
O(N). N은 꼭짓점 개수. 한 바퀴 돌면서 곱 두 개 누적하는 게 다다.

### 구현 포인트
- point[0] 를 뒤에 한 번 더 붙여놨다. 마지막 점 > 첫 점 잇는 걸 % 안 쓰고 처리하려고
- 좌표 도는 방향에 따라 부호가 뒤집히니까 abs 씌우고 반 나눠야지
- 좌표가 10만 단위라 곱이 커지는데 파이썬 정수는 알아서 버틴다. C++로 옮길 거면 long long
- 포맷 안 하고 abs(a-b)*0.5 그대로 뱉는다. 좌표가 정수라 면적이 .0 아니면 .5로만 떨어져서 소수 첫째 자리 요구랑 알아서 맞는 것
