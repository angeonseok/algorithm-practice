# 11438.LCA 2

## 문제 설명
N(2 ≤ N ≤ 100,000)개의 정점으로 이루어진 트리가 주어진다. 트리의 각 정점은 1번부터 N번까지 번호가 매겨져 있으며, 루트는 1번이다.
두 노드의 쌍 M(1 ≤ M ≤ 100,000)개가 주어졌을 때, 두 노드의 가장 가까운 공통 조상이 몇 번인지 출력한다.

## 입력
첫째 줄에 노드의 개수 N이 주어지고, 다음 N-1개 줄에는 트리 상에서 연결된 두 정점이 주어진다. 그 다음 줄에는 가장 가까운 공통 조상을 알고싶은 쌍의 개수 M이 주어지고, 다음 M개 줄에는 정점 쌍이 주어진다.

## 출력
M개의 줄에 차례대로 입력받은 두 정점의 가장 가까운 공통 조상을 출력한다.

## 풀이 정리

### 핵심 아이디어
N도 10만 M도 10만이라 한 칸씩 거슬러 올라가면 죽는다. 희소 배열 깔고 2^k칸씩 점프하는 LCA.

### 시간복잡도
O(N log N + M log N). 테이블 채우는 데 N log N, 질의 하나당 log N.

### 구현 포인트
- bfs로 깊이랑 바로 위 부모(parent[0])부터 채우고, parent[k][v] = parent[k-1][parent[k-1][v]]로 나머지 완성
- 깊이 차를 diff & (1 << k) 비트로 보면서 깊은 쪽만 먼저 끌어올림
- 깊이 맞췄는데 u == v면 그놈이 바로 답. 이거 안 걸러내면 아래 루프에서 답이 이상해짐
- 마지막 루프는 큰 점프부터 내려오면서 조상이 다를 때만 같이 올린다. 끝나면 parent[0][u]가 lca
