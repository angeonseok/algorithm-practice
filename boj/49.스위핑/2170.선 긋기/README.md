# 2170.선 긋기

## 문제 설명
매우 큰 도화지에 자를 대고 선을 그으려고 한다. 선을 그을 때에는 자의 한 점에서 다른 한 점까지 긋게 된다. 선을 그을 때에는 이미 선이 있는 위치에 겹쳐서 그릴 수도 있는데, 여러 번 그은 곳과 한 번 그은 곳의 차이를 구별할 수 없다고 하자.
이와 같은 식으로 선을 그었을 때, 그려진 선(들)의 총 길이를 구하는 프로그램을 작성하시오. 선이 여러 번 그려진 곳은 한 번씩만 계산한다.

## 입력
첫째 줄에 선을 그은 횟수 N (1 ≤ N ≤ 1,000,000)이 주어진다. 다음 N개의 줄에는 선을 그을 때 선택한 두 점의 위치 x, y (-1,000,000,000 ≤ x < y ≤ 1,000,000,000)가 주어진다.

## 출력
첫째 줄에 그은 선의 총 길이를 출력한다.

## 풀이 정리

### 핵심 아이디어
겹치는 구간 합치기. 시작점 기준으로 정렬해두면 겹칠 놈들끼리 붙어있으니 왼쪽부터 한 번 훑으면서 현재 구간을 늘리거나 끊으면 됨.

### 시간복잡도
O(N log N). 정렬이 제일 비싸고 나머진 한 번 훑는 거라 상수.

### 구현 포인트
- 좌표가 ±10억이라 배열 직접 만들 생각 하면 안 된다. 구간 그대로 들고 정렬
- start <= cur_end면 겹치는 거니까 cur_end = max(end, cur_end)로 늘리기만 함. end가 더 작은 완전 포함 케이스가 여기 걸린다
- 루프 끝나고 마지막 남은 구간 길이 더하는 거 빼먹지 말자
