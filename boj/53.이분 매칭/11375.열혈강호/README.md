# 11375.열혈강호

## 문제 설명
강호네 회사에는 직원이 N명이 있고, 해야할 일이 M개가 있다. 직원은 1번부터 N번까지 번호가 매겨져 있고, 일은 1번부터 M번까지 번호가 매겨져 있다.
각 직원은 자신이 할 수 있는 일들 중 한 개의 일만 담당할 수 있고, 각각의 일을 담당하는 사람은 1명이어야 한다.
각각의 직원이 할 수 있는 일의 목록이 주어졌을 때, M개의 일 중에서 최대 몇 개를 할 수 있는지 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 직원의 수 N과 일의 개수 M이 주어진다. (1 ≤ N, M ≤ 1,000)
둘째 줄부터 N개의 줄의 i번째 줄에는 i번 직원이 할 수 있는 일의 개수와 할 수 있는 일의 번호가 주어진다.

## 출력
첫째 줄에 강호네 회사에서 할 수 있는 일의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
직원 - 일 이분 그래프 최대 매칭. 왼쪽 정점 하나씩 잡고 dfs로 증가 경로를 찾는데, 원하는 일이 이미 차 있으면 그놈을 다른 데로 밀어보고 성공하면 뺏는 식.

### 시간복잡도
O(V * E). 왼쪽 정점 1000개마다 dfs 한 번씩 도니까 최악 정점수 * 간선수.

### 구현 포인트
- dfs 조건 한 줄이 전부다. 비어있거나(match_right[u] == -1), 차지중인 놈을 옮길 수 있으면(dfs 재귀 성공) 매칭
- visited는 정점 하나 시도할 때마다 새로 만들어야 함. 재활용하면 밀어내기가 막힘
- match_left, match_right 양쪽 다 갱신해야 다음 재귀에서 제대로 밀림
- 입력 첫 수가 할 수 있는 일 개수라 arr[1:cnt+1]로 잘라 씀. 입력 순서를 잘 봐야함
