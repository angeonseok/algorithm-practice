# 2609.최대공약수와 최소공배수

## 문제 설명
두 개의 자연수를 입력받아 최대 공약수와 최소 공배수를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에는 두 개의 자연수가 주어진다. 이 둘은 10,000이하의 자연수이며 사이에 한 칸의 공백이 주어진다.

## 출력
첫째 줄에는 입력으로 주어진 두 수의 최대공약수를, 둘째 줄에는 입력으로 주어진 두 수의 최소 공배수를 출력한다.

## 풀이 정리

### 핵심 아이디어
유클리드 호제법으로 gcd 뽑고, 최소공배수는 두 수 곱한 걸 gcd로 나누면 그냥 나온다.

### 시간복잡도
O(log min(a,b)). 나머지 연산 한 번에 값이 확 줄어서 금방 끝남.

### 구현 포인트
- while b: a, b = b, a % b 이 두 줄이 gcd 전부다
- lcm은 a * b // gcd. / 쓰면 실수 되니까 // 로 나눠야 함
- gcd를 재귀 말고 while로 짰다. 스택 걱정 없으니 이쪽이 마음 편함
