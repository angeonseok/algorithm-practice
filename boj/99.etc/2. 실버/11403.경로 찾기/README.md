# 11403.경로 찾기

## 문제 설명
가중치 없는 방향 그래프 G가 주어졌을 때, 모든 정점 (i, j)에 대해서, i에서 j로 가는 길이가 양수인 경로가 있는지 없는지 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 정점의 개수 N (1 ≤ N ≤ 100)이 주어진다. 둘째 줄부터 N개 줄에는 그래프의 인접 행렬이 주어진다. i번째 줄의 j번째 숫자가 1인 경우에는 i에서 j로 가는 간선이 존재한다는 뜻이고, 0인 경우는 없다는 뜻이다. i번째 줄의 i번째 숫자는 항상 0이다.

## 출력
총 N개의 줄에 걸쳐서 문제의 정답을 인접행렬 형식으로 출력한다. 정점 i에서 j로 가는 길이가 양수인 경로가 있으면 i번째 줄의 j번째 숫자를 1로, 없으면 0으로 출력해야 한다.

## 풀이 정리

### 핵심 아이디어
모든 경로의 가능여부 + 행렬형태 자료 > 플로이드 씀. 0을 INF로 갈아끼워 거리 문제로 만들고 돌린 다음, 도달 가능하면 1로 되칠한다.

### 시간복잡도
O(N^3). N이 100이라 100만 번, 넉넉하다.

### 구현 포인트
- 간선 없음(0)을 INF로 바꿔야 완화가 제대로 먹힘
- dist[i][k] 가 INF면 continue 로 가지치기. 안쪽 j 루프를 통째로 아낌
- 길이가 양수인 경로를 묻는 거라 대각선도 0 말고 INF에서 시작해야지. 사이클 타고 돌아오면 그때 1
- 마지막에 INF 여부로 1/0 다시 칠하고 print(*row) 로 양식 맞추기
