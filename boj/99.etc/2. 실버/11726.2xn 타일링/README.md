# 11726.2xn 타일링

## 문제 설명
2*n 크기의 직사각형을 1*2, 2*1 타일로 채우는 방법의 수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 n이 주어진다. (1 ≤ n ≤ 1,000)

## 출력
첫째 줄에 2*n 크기의 직사각형을 채우는 방법의 수를 10,007로 나눈 나머지를 출력한다.

## 풀이 정리

### 핵심 아이디어
맨 오른쪽에 세로 하나 세우거나 가로 두 개 눕히거나 둘 중 하나뿐이라 dp[i] = dp[i-1] + dp[i-2]. 결국 피보나치다.

### 시간복잡도
O(N). n이 1000이라 for 한 바퀴로 충분.

### 구현 포인트
- dp[1] = 1, dp[2] = 2 로 시작. n이 1인데 dp[2] 건드리면 인덱스 나가서 n >= 1 / n >= 2 로 감쌈
- 매 계산마다 10007로 나눠줘야 수가 안 커짐
- 점화식이 안 보이면 n = 1, 2, 3 손으로 좀 적어보면 견적 나온다
