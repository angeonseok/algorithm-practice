# 11727.2xn 타일링 2

## 문제 설명
2*n 직사각형을 1*2, 2*1과 2*2 타일로 채우는 방법의 수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 n이 주어진다. (1 ≤ n ≤ 1,000)

## 출력
첫째 줄에 2*n 크기의 직사각형을 채우는 방법의 수를 10,007로 나눈 나머지를 출력한다.

## 풀이 정리

### 핵심 아이디어
dp로 간다. 마지막에 세로 1칸 붙이는 경우 + 가로 2개짜리나 2x2 붙이는 경우 두 갈래라 dp[i] = dp[i-1] + 2*dp[i-2] 가 나옴.

### 시간복잡도
O(N). 3부터 n까지 한 번 훑으면서 칸 채우는 게 전부다.

### 구현 포인트
- dp[1]=1, dp[2]=3 초기값 박고 시작. n이 1이나 2면 인덱스 나가니까 if로 막아둠
- 10007 나머지는 매 칸마다 취해야지. 끝까지 갔다가 몰아서 하면 수가 커진다
- 2x2 타일이랑 가로 2칸 두 장이 별개 경우라서 dp[i-2]에 2 곱하는 거임
