# 1676.팩토리얼 0의 개수

## 문제 설명
N!에서 뒤에서부터 처음 0이 아닌 숫자가 나올 때까지 0의 개수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N이 주어진다. (0 ≤ N ≤ 500)

## 출력
첫째 줄에 구한 0의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
N이 500밖에 안 돼서 파이썬 큰 수 믿고 팩토리얼 통째로 곱했다. 문자열로 바꿔 뒤에서부터 0 세면 끝.

### 시간복잡도
O(N * 자릿수). 500! 곱하는 게 제일 비싸고 0 세는 건 금방 끊긴다.

### 구현 포인트
- 파이썬이라 오버플로 걱정 없이 이 짓이 가능. C++이면 2랑 5 개수 세는 쪽으로 갈아타야 함
- reversed로 뒤에서 보다가 0 아닌 놈 만나면 바로 break
- n=0이면 fac 안쪽 루프가 아예 안 돌아서 1이 나온다. 끝자리가 0이 아니라 답도 0. 따로 안 막아도 됨
