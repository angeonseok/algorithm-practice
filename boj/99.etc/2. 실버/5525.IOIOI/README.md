# 5525.IOIOI

## 문제 설명
+1개의 I와 N개의 O로 이루어져 있으면, I와 O이 교대로 나오는 문자열을 PN이라고 한다.
P1 IOI
P2 IOIOI
P3 IOIOIOI
PN IOIOI...OI (O가 N개)
I와 O로만 이루어진 문자열 S와 정수 N이 주어졌을 때, S안에 PN이 몇 군데 포함되어 있는지 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N이 주어진다. 둘째 줄에는 S의 길이 M이 주어지며, 셋째 줄에 S가 주어진다.

## 출력
S에 PN이 몇 군데 포함되어 있는지 출력한다.

## 풀이 정리

### 핵심 아이디어
I 만나면 거기서부터 OI가 몇 번 이어지는지 세고, 센 만큼 포인터를 앞으로 밀어버리는 한 번 훑기 각. 근데 while 안쪽이 비어있어서 아직 짜다 만 상태다.

### 시간복잡도
O(M) 목표. 이미 센 구간을 다시 안 보고 포인터를 그 끝까지 밀면 문자열 한 번 훑고 끝남.

### 구현 포인트
- while 조건이 i < m-2인 건 IOI 최소 길이가 3이라 뒤 2칸은 볼 필요 없어서
- OI 반복이 n번 이상이면 (반복수 - n + 1)개를 세면 됨
- 포인터를 센 구간 끝으로 밀어야지, i += 1로만 가면 같은 구간 또 세다가 O(NM)으로 터짐
