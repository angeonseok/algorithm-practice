# 1074.Z

## 문제 설명
수는 크기가 2N * 2N인 2차원 배열을 Z모양으로 탐색하려고 한다. 예를 들어, 2*2배열을 왼쪽 위칸, 오른쪽 위칸, 왼쪽 아래칸, 오른쪽 아래칸 순서대로 방문하면 Z모양이다.
(그림있음)
N > 1인 경우, 배열을 크기가 2N-1 * 2N-1로 4등분 한 후에 재귀적으로 순서대로 방문한다.
다음 예는 22 * 22 크기의 배열을 방문한 순서이다.
(그림있음)
N이 주어졌을 때, r행 c열을 몇 번째로 방문하는지 출력하는 프로그램을 작성하시오.
다음은 N=3일 때의 예이다.
(그림있음)

## 입력
첫째 줄에 정수 N, r, c가 주어진다.

## 출력
r행 c열을 몇 번째로 방문했는지 출력한다.

## 풀이 정리

### 핵심 아이디어
배열을 직접 만들다가 시간 터짐. 좌표가 어느 사분면에 있는지만 보면서 그 앞 사분면 칸수를 다 더하고 반갈해서 내려감.

### 시간복잡도
O(N). 한 단계마다 판이 반으로 줄어서 재귀 깊이가 딱 N.

### 구현 포인트
- 2^N을 통째로 넘기고 half = n // 2, area = half * half로 계속 반갈
- 2/3/4사분면은 area를 1/2/3배로 더하고 좌표를 half만큼 빼서 내려감
- n == 1이면 0 리턴이 바닥. 여기까지 쌓인 area 합만 남는다
- N이 15면 판이 2^15 * 2^15잖. 배열 만들 생각을 하면 안 됨
