# 1933.간단한 N의 약수

## 문제 설명
입력으로 1개의 정수 N 이 주어진다.
정수 N 의 약수를 오름차순으로 출력하는 프로그램을 작성하라.

## 제약사항
N은 1이상 1,000이하의 정수이다. (1 ≤ N ≤ 1,000)

## 입력
입력으로 정수 N 이 주어진다.

## 출력
정수 N 의 모든 약수를 오름차순으로 출력한다.

## 풀이 정리

### 핵심 아이디어
1부터 n까지 돌면서 나눠떨어지는 놈만 출력. n이 1000까지라 root n으로 줄일 이유가 없다.

### 시간복잡도
O(N). 걍 한 바퀴 돈다.

### 구현 포인트
- range(1, n+1)이라 n 자기 자신도 약수로 찍혀야 정상
- 출력이 공백 구분이라 end=" " / cout << ' ' 붙임
- n이 1이면 1만 찍힌다. 예외 처리 따로 안 해도 루프가 알아서 해결
