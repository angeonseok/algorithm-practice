# 1936.1대1 가위바위보

## 문제 설명
A와 B가 가위바위보를 하였다.
가위는 1, 바위는 2, 보는 3으로 표현되며 A와 B가 무엇을 냈는지 입력으로 주어진다.
A와 B중에 누가 이겼는지 판별해보자. 단, 비기는 경우는 없다.

## 입력
입력으로 A와 B가 무엇을 냈는지 빈 칸을 사이로 주어진다.

## 출력
A가 이기면 A, B가 이기면 B를 출력한다.

## 풀이 정리

### 핵심 아이디어
비기는 경우가 없다니까 A가 이기는 조합 3개만 적어놓고 나머진 전부 B.

### 시간복잡도
O(1). 조건문 한 줄.

### 구현 포인트
- 가위1 바위2 보3이라 A 승리는 (1,3), (2,1), (3,2) 딱 세 개
- else로 다 몰아버려도 되는 건 무승부가 없어서다
- cpp는 'A' 문자로 출력, py는 문자열로 출력

### 실수했던 점

### 풀이 언어
Python, C++
