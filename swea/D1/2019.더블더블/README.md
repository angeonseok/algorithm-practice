# 2019.더블더블

## 문제 설명
1부터 주어진 횟수까지 2를 곱한 값(들)을 출력하시오.
주어질 숫자는 30을 넘지 않는다.

## 풀이 정리

### 핵심 아이디어
2^0부터 2^n까지 쭉 출력. n이 30 넘지 않는다 해서 그냥 곱해도 안 터진다.

### 시간복잡도
O(N). cpp는 매번 처음부터 곱해서 O(N^2)인데 N이 30이라 티도 안 남.

### 구현 포인트
- py는 2 ** i로 바로 뽑고, cpp는 안쪽 루프로 i번 곱해서 만든다. 결과는 같은데 방식이 다름
- 1(2^0)부터 시작이라 range(0, n+1)로 잡아야 개수가 맞음
- 30제곱까지는 int 범위 안이라 자료형 걱정 없다
