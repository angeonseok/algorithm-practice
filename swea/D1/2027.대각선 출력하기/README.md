# 2027.대각선 출력하기

## 문제 설명
주어진 텍스트를 그대로 출력하세요.

## 풀이 정리

### 핵심 아이디어
5x5 대각선 무늬 찍기. cpp는 다섯 줄 그냥 박아버렸고, py는 '+'*i + '#' + 나머지로 만들어서 찍음.

### 시간복잡도
O(N^2). N이 5 고정이라 사실상 상수.

### 구현 포인트
- py는 i번째 줄에서 #이 i열에 오게 앞뒤 '+' 개수를 i랑 n-1-i로 나눔
- cpp는 텍스트 그대로 내놓으라는 문제라 출력을 통째로 하드코딩했다
- n=5 고정. 크기 바뀌면 py 버전만 그대로 쓸 수 있음

### 풀이 언어
