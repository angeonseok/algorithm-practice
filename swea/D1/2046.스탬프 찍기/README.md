# 2046.스탬프 찍기

## 문제 설명
주어진 숫자만큼 # 을 출력해보세요.
주어질 숫자는 100,000 이하다.

## 풀이 정리

### 핵심 아이디어
출력할 게 # n개뿐이라 셀 것도 없다. py랑 cpp가 만드는 방식만 다름.

### 시간복잡도
O(N). n이 10만이라 루프로 돌려도 부담 없다.

### 구현 포인트
- py는 '#' * n으로 문자열 하나 만들어서 print 한 번, cpp는 10만 번 cout 돌린다
- cpp에 endl 안 섞은 게 다행. 10만 번 flush 하면 괜히 느려짐
- 구분자 없이 # 만 이어 붙여야 함. 중간에 개행 끼면 오답

### 풀이 언어
