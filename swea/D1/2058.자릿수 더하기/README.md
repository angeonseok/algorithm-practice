# 2058.자릿수 더하기

## 문제 설명
하나의 자연수를 입력 받아 각 자릿수의 합을 계산하는 프로그램을 작성하라.

## 제약사항
자연수 N은 1부터 9999까지의 자연수이다. (1 ≤ N ≤ 9999)

## 입력
입력으로 자연수 N이 주어진다.

## 출력
각 자릿수의 합을 출력한다.

## 풀이 정리

### 핵심 아이디어
자릿수 다 더하면 됨. C++은 10으로 나누면서 나머지 뽑고, 파이썬은 걍 문자열로 받아서 한 글자씩 int 변환.

### 시간복잡도
O(log N). 돌아가는 횟수가 자릿수만큼임.

### 구현 포인트
- 얘는 테스트케이스 T가 없다. 숫자 하나 딸랑 들어옴
- C++은 n % 10 으로 뽑고 n /= 10 으로 밀어냄. 파이썬은 str 씌워서 순회. 같은 짓 다른 방식
- while(n != 0) 라서 0 들어오면 0 나오는데 입력이 자연수라 ㄱㅊ
