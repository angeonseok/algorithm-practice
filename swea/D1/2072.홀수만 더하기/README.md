# 2072.홀수만 더하기

## 문제 설명
10개의 수를 입력 받아, 그 중에서 홀수만 더한 값을 출력하는 프로그램을 작성하라.

## 제약사항
각 수는 0 이상 10000 이하의 정수이다.

## 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 10개의 수가 주어진다.

## 출력
출력의 각 줄은 '#t'로 시작하고, 공백을 한 칸 둔 다음 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
10개 중 홀수만 골라서 더함. num % 2 != 0 체크 하나.

### 시간복잡도
O(T * 10). 케이스마다 10개 한 번씩 본다.

### 구현 포인트
- % 2 == 1 대신 % 2 != 0 으로 씀. 음수 들어오면 언어마다 나머지 부호가 갈리는데 이건 자연수라 상관없음
- C++은 읽자마자 판정해서 더하고 파이썬은 리스트로 받아서 순회. 나오는 값은 같음
- ans는 케이스마다 초기화. 밖에 빼두면 다음 케이스에 누적된다

### 실수했던 점

### 풀이 언어
Python, C++
