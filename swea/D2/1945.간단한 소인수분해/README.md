# 1945.간단한 소인수분해

## 문제 설명
숫자 N은 아래와 같다.
N=2^a x 3^b x 5^c x 7^d x 11^e
N이 주어질 때 a, b, c, d, e 를 출력하라.

## 제약사항
N은 2 이상 10,000,000 이하이다.

## 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.
각 테스트 케이스의 첫 번째 줄에 N 이 주어진다.

## 출력
출력의 각 줄은 '#t'로 시작하고, 공백을 한 칸 둔 다음 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
N = 2^a * 3^b * 5^c * 7^d * 11^e 형태라고 문제가 대놓고 알려줬으니 그냥 2, 3, 5, 7, 11 순서로 나눠떨어질 때까지 나누면서 횟수만 세면 끝. 소인수 후보가 다섯 개로 고정이라 소수 판별 같은 건 필요 없다.

### 시간복잡도
O(T * log N). 나눌 때마다 최소 절반씩 줄어드니까 while 도는 횟수가 log 수준이고, 안쪽 분기는 상수 5개뿐임.

### 구현 포인트
- 2 > 3 > 5 > 7 > 11 순으로 elif라서 한 바퀴에 소인수 하나만 처리함. 어차피 while이 다시 도니까 지수는 알아서 다 세진다
- 종료 조건은 n == 1. 11까지 다 나누면 반드시 1로 떨어진다는 게 문제 보장이라 무한루프 걱정 없음
- 파이썬은 마지막을 else로 퉁쳐서 11 담당시켰고, C++은 else if(n % 11 == 0)까지 명시함. 다섯 개 밖의 소인수가 들어오면 둘 다 못 버티는 건 똑같다
- 카운트는 파이썬이 ans 5칸 리스트, C++은 a~e 변수 다섯 개. 출력 양식 '#t' 뒤 공백 하나 조심
