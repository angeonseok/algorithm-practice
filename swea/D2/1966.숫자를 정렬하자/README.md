# 1966.숫자를 정렬하자

## 문제 설명
주어진 N 길이의 숫자열을 오름차순으로 정렬하여 출력하라.

## 제약사항
N 은 5 이상 50 이하이다.

## 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.
각 테스트 케이스의 첫 번째 줄에 N 이 주어지고, 다음 줄에 N 개의 숫자가 주어진다.

## 출력
출력의 각 줄은 '#t'로 시작하고, 공백을 한 칸 둔 다음 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
말 그대로 정렬해서 뱉으면 끝. 내장 sort 한 줄이 전부라 여긴 걍 넘어가자.

### 시간복잡도
O(T * N log N). 정렬이 전부고 N은 50 이하.

### 구현 포인트
- '#t' 뒤에 공백 한 칸 두고 같은 줄에 쭉 이어 찍는 양식
- 파이썬은 문자열에 str(i) + " " 붙여서 만들다 보니 끝에 공백이 하나 남는데, SWEA 채점은 안 물고 늘어짐
- C++도 똑같이 값 뒤에 공백 붙이고 마지막에 개행. 두 풀이 로직 차이 없다
