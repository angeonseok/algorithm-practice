# 1974.스도쿠 검증

## 문제 설명
스도쿠는 숫자퍼즐로, 가로 9칸 세로 9칸으로 이루어져 있는 표에 1 부터 9 까지의 숫자를 채워넣는 퍼즐이다.
같은 줄에 1 에서 9 까지의 숫자를 한번씩만 넣고, 3 x 3 크기의 작은 격자 또한, 1 에서 9 까지의 숫자가 겹치지 않아야 한다.
입력으로 9 X 9 크기의 스도쿠 퍼즐의 숫자들이 주어졌을 때, 위와 같이 겹치는 숫자가 없을 경우, 1을 정답으로 출력하고 그렇지 않을 경우 0 을 출력한다.

## 제약사항
1. 퍼즐은 모두 숫자로 채워진 상태로 주어진다.
2. 입력으로 주어지는 퍼즐의 모든 숫자는 1 이상 9 이하의 정수이다.

## 입력
입력은 첫 줄에 총 테스트 케이스의 개수 T가 온다.
다음 줄부터 각 테스트 케이스가 주어진다.
테스트 케이스는 9 x 9 크기의 퍼즐의 데이터이다.

## 출력
테스트 케이스 t에 대한 결과는 “#t”을 찍고, 한 칸 띄고, 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
합이 45임을 이용해서 판별. 값이 1~9로만 주어진다는 제약이 있으니 행/열/3x3 박스 합이 전부 45면 겹치는 놈이 없다는 뜻이 된다.

### 시간복잡도
O(T * 9^3). 파이썬은 81칸마다 check(i, j)를 불러서 행/열/박스를 매번 다시 훑는 구조라 2천 번쯤 되고, C++은 행 9 + 열 9 + 박스 9만 봐서 O(T * 81)로 끝남.

### 구현 포인트
- 박스 시작 좌표는 (x // 3) * 3, (y // 3) * 3. 이 3으로 나누고 다시 3 곱하는 걸 놓치면 박스가 겹쳐서 잡힌다
- 파이썬은 칸마다 check(i, j) 호출이라 같은 행/열/박스를 아홉 번씩 중복 검사하는 구조. C++은 행 9번 + 열 9번 + 박스 9번만 딱 검사해서 낭비가 없다
- 파이썬 쪽은 flag 내려도 안쪽 break만으론 못 빠져나오니 바깥 루프에서 한 번 더 break 걸어줘야 함
- 합 45 트릭은 1~9 정수 보장이 깔려야 성립. 제약 안 읽고 쓰면 위험한 방법이다
