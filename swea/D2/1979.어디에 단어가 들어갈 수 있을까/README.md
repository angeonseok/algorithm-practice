# 1979.어디에 단어가 들어갈 수 있을까

## 문제 설명
N X N 크기의 단어 퍼즐을 만들려고 한다. 입력으로 단어 퍼즐의 모양이 주어진다.
주어진 퍼즐 모양에서 특정 길이 K를 갖는 단어가 들어갈 수 있는 자리의 수를 출력하는 프로그램을 작성하라.

## 예제
N = 5, K = 3 이고, 퍼즐의 모양이 아래 그림과 같이 주어졌을 때
길이가 3 인 단어가 들어갈 수 있는 자리는 2 곳(가로 1번, 가로 4번)이 된다.

## 제약사항
1. N은 5 이상 15 이하의 정수이다. (5 ≤ N ≤ 15)
2. K는 2 이상 N 이하의 정수이다. (2 ≤ K ≤ N)

## 입력
입력은 첫 줄에 총 테스트 케이스의 개수 T가 온다.
다음 줄부터 각 테스트 케이스가 주어진다.
테스트 케이스의 첫 번째 줄에는 단어 퍼즐의 가로, 세로 길이 N 과, 단어의 길이 K 가 주어진다.
테스트 케이스의 두 번째 줄부터 퍼즐의 모양이 2차원 정보로 주어진다.
퍼즐의 각 셀 중, 흰색 부분은 1, 검은색 부분은 0 으로 주어진다.

## 출력
테스트 케이스 t에 대한 결과는 “#t”을 찍고, 한 칸 띄고, 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
가로로 한 번, 세로로 한 번 훑으면서 연속된 1의 길이를 세다가 0을 만나면 끊고 그 길이가 딱 K인지 본다. 길이가 K보다 길면 안 되는 거라 == 비교여야 함.

### 시간복잡도
O(T * N^2). 행 방향 N^2, 열 방향 N^2 두 번. N이 15 이하라 껌.

### 구현 포인트
- cnt == K를 체크하는 건 0을 만났을 때. 그리고 cnt는 바로 0으로 리셋해야 다음 구간이 안 섞인다
- 행 끝까지 1로 채워진 경우엔 0을 만날 일이 없으니, 안쪽 루프 끝나고 cnt == K를 한 번 더 봐줘야 함. 이거 빼먹으면 오른쪽 끝/아래쪽 끝 자리를 통째로 날린다
- 세로 훑을 땐 arr[j][i]로 인덱스 뒤집기. 배열 전치할 필요 없이 이거면 끝
- cnt >= K가 아니라 == K. K보다 긴 구간은 단어가 딱 안 맞으니 자리가 아님
