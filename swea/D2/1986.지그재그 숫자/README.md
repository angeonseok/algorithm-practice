# 1986.지그재그 숫자

## 문제 설명
1부터 N까지의 숫자에서 홀수는 더하고 짝수는 뺐을 때 최종 누적된 값을 구해보자.

## 예제 풀이
N이 5일 경우,
1 - 2 + 3 - 4 + 5 = 3
N이 6일 경우,
1 - 2 + 3 - 4 + 5 - 6 = -3

## 제약사항
N은 1 이상 10 이하의 정수이다. (1 ≤ N ≤ 10)

## 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.
각 테스트 케이스에는 N이 주어진다.

## 출력
각 줄은 '#t'로 시작하고, 공백을 한 칸 둔 다음 누적된 값을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
1부터 N까지 돌면서 홀수면 더하고 짝수면 빼면 끝. 식 유도할 것도 없이 그냥 뇌빼고 돌림.

### 시간복잡도
O(T * N). N이 10 이하라 반복문으로 긁어도 남아돈다.

### 구현 포인트
- i % 2 로 홀짝 갈라서 부호만 뒤집어주면 됨
- ans는 테스트케이스마다 0으로 초기화해야지
- 출력 양식 #t 맞추기
- .py / .cpp 둘 다 같은 반복문, 그대로 이식한 수준
