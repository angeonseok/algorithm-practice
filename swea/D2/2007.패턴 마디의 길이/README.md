# 2007.패턴 마디의 길이

## 문제 설명
패턴에서 반복되는 부분을 마디라고 부른다. 문자열을 입력 받아 마디의 길이를 출력하는 프로그램을 작성하라.

## 제약사항
각 문자열의 길이는 30이다. 마디의 최대 길이는 10이다.

## 입력
가장 첫 줄에는 테스트 케이스의 개수 T가 주어지고, 그 아래로 각 테스트 케이스가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 길이가 30인 문자열이 주어진다.

## 출력
출력의 각 줄은 '#t'로 시작하고, 공백을 한 칸 둔 다음 정답을 출력한다.
(t는 테스트 케이스의 번호를 의미하며 1부터 시작한다.)

## 풀이 정리

### 핵심 아이디어
마디 길이 i를 1부터 10까지 대보면서 s[l] == s[l-i] 가 끝까지 버티는 첫 i를 답으로 뱉는다. 마디면 i칸 떨어진 놈끼리 항상 같아야 하니까.

### 시간복잡도
O(T * 10 * 30). 마디 후보 10개 x 문자열 길이 30, 사실상 상수.

### 구현 포인트
- 문자열 길이가 30 고정이라 안쪽 루프 끝을 그냥 30으로 박아둠
- 작은 i부터 보니까 처음 통과한 놈이 최소 마디, 찾으면 바로 break
- 파이썬 쪽 l += 1 은 for가 알아서 돌려주는 거라 없어도 되는 줄
