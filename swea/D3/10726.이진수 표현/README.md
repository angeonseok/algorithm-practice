# 10726.이진수 표현

## 문제 설명
정수 N, M 이 주어질 때, M의 이진수 표현의 마지막 N 비트가 모두 1로 켜져 있는지 아닌지를 판별하여 출력하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다.
이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다.
각 테스트 케이스는 다음과 같이 구성되었다.
첫 번째 줄에 정수 N, M이 주어진다. (1 ≤ N ≤ 30 , 0 ≤ M ≤ 108)

## 출력
각 테스트 케이스마다 한 줄씩
마지막 N개의 비트가 모두 켜져 있다면 ON
아니면 OFF 를 출력하라.

## 풀이 정리

### 핵심 아이디어
1이 n개 붙은 마스크 만들어서 m이랑 AND. 결과가 마스크 그대로 나오면 하위 n비트가 전부 켜진 거.

### 시간복잡도
O(T * N). 마스크 만드는 데 N, 비교는 상수.

### 구현 포인트
- 마스크는 "1"*n 을 int(t, 2)로 변환해서 뽑았다. (1 << n) - 1 이랑 같은 값
- 비교는 == bits 로 해야지 != 0 으로 두면 비트 하나만 켜져도 통과해버림
- 출력은 숫자가 아니라 ON / OFF 문자열
