# 11315.오목 판정

## 문제 설명
N X N 크기의 판이 있다. 판의 각 칸에는 돌이 있거나 없을 수 있다. 돌이 가로, 세로, 대각선 중 하나의 방향으로 다섯 개 이상 연속한 부분이 있는지 없는지 판정하는 프로그램을 작성하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 하나의 정수 N(5 ≤ N ≤ 20)이 주어진다.
다음 N개의 줄의 각 줄에는 길이 N인 문자열이 주어진다. 각 문자는 'o'또는 '.'으로, 'o'는 돌이 있는 칸을 의미하고, '.'는 돌이 없는 칸을 의미한다.

## 출력
각 테스트 케이스 마다 돌이 다섯 개 이상 연속한 부분이 있으면 “YES”를, 아니면 “NO”를 출력한다.

## 풀이 정리

### 핵심 아이디어
판 전부 훑으면서 돌 있는 칸에서만 4방향으로 뻗어본다. 반대 방향은 어차피 반대쪽 돌이 시작점 될 때 걸리니까 8방향 다 볼 이유가 없음. py는 while로 연속 개수를 세고, cpp는 아예 k를 0~4로 고정해서 다섯 칸 채워지나만 확인.

### 시간복잡도
O(T * N^3). 칸마다 4방향 뻗는데 py는 한 방향에서 최대 N칸까지 세니까 저렇게 됨. cpp는 5칸에서 끊어서 더 싸다. N이 20 이하라 뭘 하든 껌.

### 구현 포인트
- 방향은 반쪽만 잡으면 충분. py는 (-1,1),(0,1),(1,1),(1,0), cpp는 (0,1),(1,0),(1,1),(1,-1) 로 고른 게 다를 뿐 같은 소리다
- 범위 밖인지 먼저 보고 문자 비교해야 한다. 인덱스 조심
- py는 cnt >= 5 되면 컷, cpp는 k == 4 찍히면 flag 세우고 컷. 세는 방식만 다르고 판정은 같음
- 찾으면 삼중 for를 다 빠져나와야 해서 py는 ans 플래그로 break 세 번, cpp는 루프 조건에 !flag를 박아둠
