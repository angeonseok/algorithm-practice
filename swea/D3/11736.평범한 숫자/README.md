# 11736.평범한 숫자

## 문제 설명
1 이상 N 이하의 정수가 적혀 있는 길이 N의 순열 p1, p2, …, pN이 있다. 수열에 있는 모든 숫자는 서로 다르다. 2 ≤ i ≤ N-1이며, pi-1, pi, pi+1 중 pi가 최솟값도, 최댓값도 아니라면 pi를 평범한 숫자라고 정의한다. 주어진 순열에서 평범한 숫자의 개수는 몇 개인가?

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다. 각 테스트 케이스는 다음과 같이 구성되었다.
∙ 첫 번째 줄에 정수 N 이 주어진다. (3 ≤ N ≤ 20)
∙ 이후 N개의 정수 pi가 주어진다. (3 ≤ pi ≤ N) 모든 pi는 서로 다르다.

## 출력
각 테스트 케이스마다 정답을 출력하라.

## 풀이 정리

### 핵심 아이디어
가운데 놈이 셋 중 최대도 최소도 아니면 평범한 숫자다. 후보가 N-2개니까 거기서 깔고 시작해서 최대거나 최소인 놈을 빼는 방향으로 갔다.

### 시간복잡도
O(T * N). 한 번 훑으면 끝나고 N도 20 이하.

### 구현 포인트
- 양 끝 두 개는 애초에 후보가 아님. range(1, n-1) 범위 조심
- ans를 n-2로 깔고 빼니까 조건이 하나로 줄어든다
- max(a,b,c) == b 거나 min(a,b,c) == b면 컷
