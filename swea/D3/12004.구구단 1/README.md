# 12004.구구단 1

## 문제 설명
정수 N이 주어졌을 때, N 이 1 이상 9 이하의 두 수 a, b의 곱으로 표현될 수 있는지 판단하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다. 각 테스트 케이스는 다음과 같이 구성되었다.
∙ 하나의 정수 N이 주어진다. (1≤N≤100)

## 출력
각 테스트 케이스마다
∙ N 이 1 이상 9 이하의 두 수 a, b의 곱으로 표현될 수 있으면 “Yes”, 아니면 “No” 를 출력하라.

## 풀이 정리

### 핵심 아이디어
9부터 1까지 내려가면서 나누어떨어지는 놈 찾고, 그때 몫도 1~9 안에 들어오면 구구단에 있는 수다. 후보가 9개뿐이라 그냥 다 봤다.

### 시간복잡도
O(T * 9). 9부터 1까지 훑어봐야 아홉 번이다.

### 구현 포인트
- 나누어떨어져도 몫이 9 넘으면 안 됨. 100 같은 놈이 여기서 걸러진다
- for-else 써서 break 한 번도 못 하면 No 출력. else가 if가 아니라 for에 붙은 거다
- 찾자마자 break. 계속 돌게 두면 Yes를 여러 번 찍는다
