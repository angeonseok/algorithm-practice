# 12221.구구단2

## 문제 설명
아기 석환이는 최근 구구단을 배웠다. 그래서 1 이상 9 이하의 자연수 두개를 곱셈할 수 있으나, 10 이상의 자연수를 곱셈하는 방법은 모른다.
두 정수 A, B가 주어진다. 아기 석환이 두 정수를 곱셈할 수 있으면 곱을 출력하고, 아니면 -1을 출력하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다. 각 테스트 케이스는 다음과 같이 구성되었다.
∙ 첫 번째 줄에 두 정수 A, B가 주어진다. (1 ≤ A, B ≤ 20)

## 출력
각 테스트 케이스마다 정답을 출력하라.

## 풀이 정리

### 핵심 아이디어
조건문 하나면 견적 나온다. a, b 둘 다 1~9면 곱하고 아니면 -1.

### 시간복잡도
O(T). 비교 두 번이 전부.

### 구현 포인트
- 한쪽만 9 이하여도 안 됨. 둘 다 검사해야지
- A, B가 20까지 들어온다. 범위 안 보고 그냥 곱하는 게 여기서 틀리는 자리
- py는 삼항식, cpp는 ?: 로 같은 식 그대로 옮긴 거라 로직 차이 없음
