# 13732.정사각형 판정

## 문제 설명
N×N 크기의 격자판이 있다. 각각의 격자는 비어 있거나(‘.’), 막혀 있다(‘#’). 이때, 막혀 있는 칸들이 하나의 정사각형을 이루는지를 판단하는 프로그램을 작성하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 격자판의 크기 N (1≤N≤20 이 주어진다. 다음 N개의 줄은 격자판의 배치를 나타내며, 각 줄에는 ‘.’ 또는 ‘#’로만 이루어진 길이가 N인 문자열이 주어진다. 모든 격자판에는 최소 1개 이상의 ‘#’ 칸이 있음이 보장된다.

## 출력
각 테스트 케이스마다 격자판의 막혀 있는 칸들이 하나의 정사각형을 이루면 ‘yes’를, 그렇지 않다면 ‘no’를 출력한다.

## 풀이 정리

### 핵심 아이디어
'#' 좌표 전부 모아서 최소/최대 행·열로 바운딩 박스를 잡는다. 그 박스가 정사각형이고 박스 칸 수랑 '#' 개수가 같으면 속이 꽉 찬 정사각형.

### 시간복잡도
O(T * N^2). N이 20이라 격자 한 번 훑는 게 제일 비싸다.

### 구현 포인트
- row == col만 보면 안 됨. 안쪽에 구멍 나 있을 수 있으니 row * col == len(pos)도 같이 봐야지
- '#'가 최소 하나는 보장돼서 max/min에 빈 리스트 들어갈 걱정은 없다
- 좌표를 (i, j) 튜플로 모아두고 max(r for r, c in pos) 식으로 행·열 따로 뽑음
