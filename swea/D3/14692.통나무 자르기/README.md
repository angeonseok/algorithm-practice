# 14692.통나무 자르기

## 문제 설명
Alice와 Bob은 길이 N미터의 통나무를 자르는 게임을 한다. 게임은 Alice가 먼저 시작하며 그 이후 둘이 번갈아가면서 턴을 가진다. 각 턴을 맡은 사람은, 통나무를 두 조각으로 나누는데, 이 때 잘린 통나무가 모두 자연수(1 이상의 정수) 미터 길이를 가지도록 잘라야 한다. 더 이상 자를 수 없게 되는 사람이 진다. 누가 이기는가?

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다. 각 테스트 케이스는 다음과 같이 구성되었다.
- 첫 번째 줄에 정수 N이 주어진다. (2≤N≤ 109)

## 출력
각 테스트 케이스 마다 한 줄씩
- Alice가 이기면 “Alice”, 아니면 “Bob” 을 출력하라.

## 풀이 정리

### 핵심 아이디어
어떻게 잘라도 조각이 한 개씩만 늘어나니까 1미터 조각만 남을 때까지의 총 자르기 횟수는 무조건 n-1로 고정. 그럼 홀짝만 보면 승자가 나온다. n-1이 홀수, 즉 n이 짝수면 선공 Alice가 마지막을 잡음.

### 시간복잡도
O(T). n 크기랑 상관없이 % 2 한 번.

### 구현 포인트
- 게임 트리나 그런디 수 파고들면 n이 커서 바로 터짐. 총 수 횟수가 상수로 정해지는 게임인 걸 먼저 알아채야 함
- 자르는 위치를 어디로 하든 결과가 안 바뀐다. 조각 수 +1 은 똑같으니까
- n=2면 Alice가 자르고 Bob은 자를 게 없어서 Alice. n=1이면 아예 못 자르는데 홀수라 식이 알아서 Bob 뱉음
