# 16910.원 안의 점

## 문제 설명
N이 주어질 때, 원점을 중심으로 반지름이 N인 원 안에 포함되는 격자점(x,y 좌표가 모두 정수인 점)의 개수를 구하는 프로그램을 작성하라.
다시 말하자면, x2+y2<=N2인 격자점의 개수를 구하는 프로그램을 작성하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 하나의 정수 N(1<=N<=200)이 주어진다.

## 출력
각 테스트 케이스마다 반지름이 N인 원 안에 포함되는 격자점의 개수를 출력한다.

## 풀이 정리

### 핵심 아이디어
n이 200밖에 안 돼서 수식 세울 것도 없이 -n~n 격자 전부 돌면서 x^2 + y^2 <= n^2 만족하는 놈 세면 됨.

### 시간복잡도
O(T * N^2). N=200이면 401*401 = 16만 정도라 뇌 빼고 이중 for 돌려도 ㄱㅊ.

### 구현 포인트
- 범위가 -n부터 n까지고 0도 포함이라 range(-n, n+1)
- 부등호가 <= 라 원 위에 딱 걸친 점도 세야 한다
- 제곱근 쓰지 말고 제곱끼리 비교. 실수 오차 낄 틈이 없다
