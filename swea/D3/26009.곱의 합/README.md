# 26009.곱의 합

## 문제 설명
세 정수 a,b,c 가 주어졌을 때, 를 998244353 으로 나눈 나머지를 출력하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다.
이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다.
각 테스트 케이스는 다음과 같이 구성되었다.
- 첫 번째 줄에 세 정수 a, b, c 가 주어진다. (1 ≤ a, b, c ≤ 109)

## 출력
각 테스트 케이스 마다 한 줄씩, 정답을 출력하라.

## 풀이 정리

### 핵심 아이디어
i j k 삼중 시그마가 그냥 세 등차합의 곱으로 쪼개진다. 가우스 공식 세 번 굴려서 곱하면 끝. 이중 for로 돌 문제가 아님.

### 시간복잡도
O(T). 공식 세 번에 곱셈 두 번.

### 구현 포인트
- a b c가 10^9라 그대로 곱하면 숫자가 커짐 > 각 항 구할 때마다 998244353으로 나눠둠
- //2 는 % 전에 끝내야 함. 나머지 취한 값에 나누기 하면 답 깨짐
- 삼중 시그마를 곱으로 분리하는 식만 손으로 한 번 적어보면 바로 견적 나옴
