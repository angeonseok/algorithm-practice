# 3131.100만 이하의 모든 소수

## 문제 설명
1 이상 100만(106) 이하의 모든 소수를 구하는 프로그램을 작성하시오.
참고로, 10 이하의 소수는 2, 3, 5, 7 이다.

## 입력
이 문제의 입력은 없다.

## 출력
1 이상 100만 이하의 소수를 공백을 사이에 두고 한 줄에 모두 출력한다.

## 풀이 정리

### 핵심 아이디어
에라토스테네스의 체 그대로. 100만개를 하나씩 소수판정 돌리면 답 없으니까 배수 지워나가는 쪽으로 감.

### 시간복잡도
O(N log log N). N은 100만. 체 한 번 돌리는 게 전부고 마지막에 True인 놈만 뽑아서 출력.

### 구현 포인트
- 0이랑 1은 소수 아니니까 미리 False로 꺼두고 시작
- 바깥 루프는 root n까지만. x = a * b 라 하면 a, b가 root x보다 클 수 없어서 그 위는 볼 이유가 없다
- 안쪽은 i*2가 아니라 i*i부터. 그 아래 배수는 더 작은 소수가 이미 다 지워놨음
- 출력은 print(*ans)로 한 방에. 하나씩 찍으면 출력만으로 시간 잡아먹음
