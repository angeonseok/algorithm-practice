# 5549.홀수일까 짝수일까

## 문제 설명
양의 정수가 주어질 때, 이 수가 홀수인지 짝수인지 판별하는 프로그램을 작성하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 100자리 이하의 양의 정수가 주어진다.

## 출력
각 테스트 케이스마다 첫 번째 줄에는‘#T’(T는 테스트케이스 번호를 의미하며 1부터 시작한다.)를 출력하고, 주어진 수가 홀수이면 “Odd”를, 짝수이면 “Even”을 출력한다.

## 풀이 정리

### 핵심 아이디어
100자리든 뭐든 파이썬은 int로 받아서 % 2 하면 끝. 사실 마지막 글자 하나만 봐도 되는 문제.

### 시간복잡도
O(T * D). D는 자릿수 100 이하. int 변환이 자릿수만큼 걸리고 나머진 상수.

### 구현 포인트
- 큰 수라고 겁먹을 거 없이 그냥 int 캐스팅. 파이썬 정수는 자릿수 제한이 없다
- n % 2 == 1 판정해서 삼항 한 줄로 처리
- input().strip() 걸어서 개행 섞여 들어오는 거 막음
