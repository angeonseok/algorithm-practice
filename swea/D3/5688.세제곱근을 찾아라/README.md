# 5688.세제곱근을 찾아라

## 문제 설명
양의 정수 N에 대해 N = X3가 되는 양의 정수X 를 구하여라.

## 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스의 첫 번째 줄에는 하나의 정수 N(1≤N≤1018) 이 주어진다.

## 출력
각 테스트 케이스마다 첫 번째 줄에는‘#T’(T는 테스트케이스 번호를 의미하며 1부터 시작한다.)를 출력하고, N = X3가 되는 양의 정수 X를 출력한다.
만약 이런 X가 존재하지 않으면 -1을 출력한다.

## 풀이 정리

### 핵심 아이디어
n ** (1/3) 올림해서 나온 값을 다시 세제곱해보고 원래 n이랑 같은지 확인한다. 파이썬 올림을 믿지말자.

### 시간복잡도
O(T). 테케당 거듭제곱 한 번, 비교 한 번.

### 구현 포인트
- 실수 세제곱근은 오차 때문에 ±1 튈 수 있는 구조라 num ** 3 == n 검증이 필수
- n이 10^18까지 가도 파이썬 int 곱셈은 안 터진다. 위험한 건 부동소수 쪽
- 조건 안 맞으면 그냥 -1
