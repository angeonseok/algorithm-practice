# 16801.식신

## 문제 설명
N명의 사람으로 이루어진 팀이 음식 먹기 대회에 출전한다. 팀의 선수는 1부터 N까지 나이 순서대로 번호가 붙어 있다. i번 선수의 먹기 능력치는 양의 정수 Ai로 표현된다. 숫자가 낮을 수록 먹는 실력이 좋은 것이다.
대회에는 N개의 음식이 제공되며, i번 음식의 난이도는 양의 정수 Fi로 표현된다. 대회의 자세한 사항은 다음과 같다.
- 팀원들은 각자 하나의 음식을 골라 먹으며, 한 음식을 여러 팀원이 같이 먹지 않는다.
- 어떠한 선수의 먹기 능력치가 x이고, 선수가 먹는 음식의 난이도가 y이면, 이 선수가 음식을 먹는데  x X y 초가 걸린다.
- 팀의 점수는, 가장 음식을 먹는 데 오래 걸린 선수가 사용한 시간(초)와 동일하다.
이 팀의 팀원들은, 대회 전 최대 K번의 트레이닝을 거치려고 한다. 한 번의 트레이닝을 거치면, 어떠한 선수의 먹기 능력치를 1씩 줄일 수 있다 (하지만 0 미만으로 내려가게 할 수는 없다).
이 때 줄이고자 하는 선수가 누구인지는 마음대로 정할 수 있다. 만약 모든 선수의 먹기 능력치가 0이면 트레이닝을 할 수 없다.
각 트레이닝 때 능력치를 줄이고자 하는 선수를 적절히 골랐다면, 팀의 점수의 최솟값은 얼마가 되는가?

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다. 각 테스트 케이스는 다음과 같이 구성되었다.
- 첫 번째 줄에 정수 N, K가 주어진다. (1 <= N <= 200000, 0 <= K <= 10^18)
- 두 번째 줄에 A1, A2, ..., AN 이 주어진다. (1 <= Ai <= 10^6)
- 세 번째 줄에 F1, F2, ..., FN 이 주어진다. (1 <= Fi<= 10^6)

## 출력
각 테스트 케이스 마다 한 줄씩 문제의 정답을 출력하라.
