# 17322.앞만 보는 나이트

## 문제 설명
(0, 0) 에 나이트 말 하나가 놓여 있다. 나이트 말은, (i, j) 위치에서 (i+1, j+2) 혹은 (i+2, j+1) 위치로 움직일 수 있다.
나이트 말이 (X, Y) 위치에 도달할 수 있는 경우의 수를 109+7 로 나눈 나머지를 출력하라.

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다.
각 테스트 케이스는 다음과 같이 구성되었다.
첫 번째 줄에 X,Y정수가 주어진다. (1≤X,Y≤10^6)

## 출력
각 테스트 케이스 마다 문제의 정답을 출력하라

## 풀이 정리

### 핵심 아이디어
단순 조합문제인줄 알았는데 페르마 소정리 문제였고. (i+1,j+2) 이동 a번, (i+2,j+1) 이동 b번을 연립해서 뽑아내면 순서 섞는 경우의 수 C(a+b, a)가 답이다.

### 시간복잡도
O(MAX + T * log MOD). 팩토리얼 200만개는 처음에 한 번만 깔고, 테케마다 역원 구하는 pow가 log MOD.

### 구현 포인트
- a = (2Y-X)/3, b = (2X-Y)/3. 3으로 안 나눠떨어지거나 음수 나오면 도달 불가라 ㅂㅂ
- a+b는 결국 (X+Y)/3이라 X,Y가 10^6이어도 66만쯤에서 끝난다. fac 2000001은 넉넉하게 잡아둔 값
- 모듈러에선 그냥 나누면 안 되니까 pow(fac[a]*fac[b], MOD-2, MOD)로 역원 곱셈
- 팩토리얼을 테케 안에서 만들면 T배로 터진다. 전역에서 미리 계산
