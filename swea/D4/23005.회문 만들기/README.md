# 23005.회문 만들기

## 문제 설명
알파벳 소문자로만 구성된 문자열 S가 있다.
당신은 아래 연산을 원하는 만큼 (0회 포함) 반복할 수 있다.
S에서 원하는 위치 (맨 앞, 맨 뒤 포함)를 하나 정하여, x를 넣는다. 즉, Python 문법으로 S = S[:k] + ‘x’ + S[k:]
S를 회문(palindrome)으로 만들기 위해 사용해야 하는 연산의 최소 횟수를 구하는 프로그램을 작성하라.
S가 회문이라는 것은, S를 앞에서부터 뒤로 읽으나 뒤에서부터 앞으로 읽으나 그 내용이 똑같다는 것이다.

## 입력
첫 번째 줄에 테스트 케이스의 수 T가 주어진다.
각 테스트 케이스는 한 개의 줄로 구성되며, 각 줄에는 알파벳 소문자로만 구성된 문자열 S가 주어진다. S의 길이는 1 이상 100,000 이하이다.

## 출력
각 테스트 케이스마다, 만약 주어진 연산만으로 S를 회문으로 만들 수 있다면 최소 연산 횟수를 출력하고, 만들 수 없다면 -1을 출력한다.
