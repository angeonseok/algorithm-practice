# 11546.주스

## 문제 설명
당신은 사과 주스 (A), 바나나 주스 (B), 당근 주스 (C)를 샀고, 이들을 적당히 섞어서 회의실에 제공할 계획이다.
회의실의 각 참석자들은 3개의 주스가 최소 어느 정도의 비율로 들어 있기를 원한다. 그들은 3개의 주스가 들어 있는 비율이 그들이 원하는 비율 이상일 때만 주스를 마신다.
당신에게 이 비율 정보가 주어졌을 때, 최대한 많은 참석자들이 마실 수 있는 비율로 주스를 섞으면 몇 명이 주스를 마실까?

## 입력
첫 번째 줄에 테스트 케이스의 수 TC가 주어진다. 이후 TC개의 테스트 케이스가 새 줄로 구분되어 주어진다. 각 테스트 케이스는 다음과 같이 구성되었다.
∙ 첫 번째 줄에 사람의 수 N이 주어진다. (1≤N≤5000)
∙ 이후 N개의 줄의 세 정수 A,B,C가 주어진다. i번째 사람은 사과 주스가 A/10000, 바나나 주스가 B/10000, 당근 주스가 C/10000 비율 이상으로 들어있기를 원한다는 뜻이다. (0≤A,B,C≤10000)

## 출력
각 테스트 케이스 마다 한 줄씩, 만족시킬 수 있는 사람의 최댓값을 출력하라.
